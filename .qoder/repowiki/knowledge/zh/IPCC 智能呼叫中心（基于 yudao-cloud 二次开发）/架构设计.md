项目采用 Maven 多模块 + Spring Boot 4.1 / Java 25 的微服务架构，根目录 `yudao-cloud/pom.xml` 作为聚合 POM，通过
`yudao-dependencies` BOM 统一管理版本，核心分层如下：

- 基础设施层：`yudao-framework` 下拆分为 `yudao-common` 与各 `yudao-spring-boot-starter-*`
  （web、security、mybatis、redis、mq、job、monitor、tenant、data-permission、websocket、rpc、protection、env、excel、test），以 starter
  形式按需装配。
- 网关与聚合启动：`yudao-gateway` 提供统一入口，`yudao-server` 为聚合启动模块，仅引入业务模块依赖并打包部署。
- 业务模块层：每个业务域（system、infra、ai、cc、crm、mall、pay、bpm、mp、report、member、iot、mes、wms、hrm、fms）均按 `*-api`
  （对外接口/枚举/常量）+ `*-server`（Spring Boot 应用 + Dockerfile）拆分；当前启用 system、infra、ai、cc 等模块，其余在顶层 POM
  中注释掉。
- 通信子系统（yudao-module-cc 内嵌）：除标准 API/server 外，还内聚两个自研开源组件——`ipcc-sipproxy`（SIP over WebSocket
  B2BUA，含 cluster/api/autoconfigure 等子包，暴露 13+ 扩展点）和 `ipcc-fs-esl`（基于 Netty 4.x 的 FreeSWITCH ESL
  客户端，提供连接管理、事件路由、分布式监听权协调），二者通过 Spring Boot AutoConfiguration 注入到 cc-server。
- 前端工程：`yudao-ui-admin-vue3` 为 Vue3 + Vite + Element Plus + TypeScript 管理后台，使用 pnpm workspace，通过 `.env.*`
  区分 dev/test/stage/prod 环境。
- 文档与脚本：`docs/` 存放 4G 网关、Voice Gateway 等技术文档；`yudao-module-cc/doc/` 含 FreeSWITCH/Coturn
  部署脚本、端到端测试套件（Python + pytest）及网络拓扑说明；`website/` 与 `yudao-prd/` 分别承载官网首页与产品原型。
  依赖方向严格自底向上：业务 server → framework starter → yudao-dependencies；各业务模块之间仅通过 `*-api` 子模块解耦。
