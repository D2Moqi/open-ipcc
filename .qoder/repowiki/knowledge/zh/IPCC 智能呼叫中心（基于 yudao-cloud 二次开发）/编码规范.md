- 每个业务模块统一拆分为 `*-api`（对外接口、枚举、错误码常量）与 `*-server`（Spring Boot 应用 + Dockerfile）两个子模块，通过
  Maven 聚合 POM 组织。
- 通用能力以 `yudao-spring-boot-starter-*` 命名封装，通过
  `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现自动装配，业务模块按需引入。
- 跨模块共享的枚举、错误码、API 常量集中放在 `*-api/src/main/java/cn/iocoder/yudao/module/<domain>/enums` 或 `constants`
  包下，避免硬编码字符串散落。
- 所有可部署服务均提供 `Dockerfile`，并通过 `yudao-server` 聚合启动，便于统一容器化与 CI 流水线。
- 前端通过 `.env.local` / `.env.dev` / `.env.test` / `.env.stage` / `.env.prod` 多环境变量文件区分构建模式，配合
  `vite --mode <env>` 切换配置。
- 数据库初始化脚本按数据库类型分目录（mysql/postgresql/oracle/sqlserver/dm/highgo/kingbase/opengauss），统一命名为
  `quartz.sql` 与 `<db>-schema.sql`，便于多库适配。
