模块采用 `yudao-module-ai-api` + `yudao-module-ai-server` 双子模块拆分：API 子模块仅暴露枚举常量（如 `AiPlatformEnum`、`AiModelTypeEnum`、各业务域状态枚举）和错误码，供其他服务引用；Server 子模块为独立 Spring Boot 应用（端口 48090），按业务域（chat/image/knowledge/mindmap/music/workflow/write/model）划分 controller → service → dal（DO + MyBatis-Plus Mapper）三层结构。

核心抽象集中在 `framework/ai/core/model`：通过 `AiModelFactory` 接口统一封装 ChatModel/ImageModel/EmbeddingModel/MidjourneyApi/SunoApi/VectorStore 的创建与缓存，具体实现 `AiModelFactoryImpl` 依据 `AiPlatformEnum` 分发到各厂商实现（OpenAI、通义千问、文心一言、智谱、DeepSeek、Gemini、Grok、Ollama、Midjourney、Suno、SiliconFlow 等），新增厂商只需在工厂注册即可接入。向量存储支持 Redis/Qdrant/Milvus 三种后端，由 `application.yaml` 中 `spring.ai.vectorstore` 配置切换。

业务层通过 `service/knowledge/splitter` 下的 MarkdownQaSplitter、SemanticTextSplitter 对文档进行分片，配合 VectorStore 实现 RAG 检索；异步任务 `job/image/AiMidjourneySyncJob`、`job/music/AiSunoSyncJob` 轮询第三方回调更新状态；工具层 `tool/function` 暴露可被 LLM 调用的 Function Calling 方法（天气查询、目录列表、用户画像等）。配置通过 `application.yaml` + Nacos 动态注入，各厂商 API Key 以环境变量形式传入。
