- 每个业务域（finance/product/purchase/sale/stock/statistics）下统一按 controller/service/dal 三层组织，且 controller 与 VO、service 与 DO、mapper 均保持同名对应关系。
- Controller 方法统一返回 `CommonResult<T>`，分页查询返回 `PageResult<T>`，并使用 `@Validated` + `@Valid` 对请求 VO 进行参数校验。
- 接口权限通过 `@PreAuthorize("@ss.hasPermission('erp:<domain>:<action>')")` 表达式声明，操作日志通过 `@ApiAccessLog(operateType = EXPORT)` 标注导出类接口。
- 枚举类型实现 `ArrayValuable<Integer>` 并提供 `ARRAYS` 静态字段，便于前端下拉框等场景直接获取键值对。
- 错误码集中定义在 `enums/ErrorCodeConstants.java`，业务异常通过 `ServiceExceptionUtil.exception` 抛出，避免在业务代码中硬编码错误信息。
- 跨表关联数据（如产品名称、仓库名）在 Controller 层通过批量查询后以 Map 形式回填到 VO，而非在 SQL 中 JOIN。
