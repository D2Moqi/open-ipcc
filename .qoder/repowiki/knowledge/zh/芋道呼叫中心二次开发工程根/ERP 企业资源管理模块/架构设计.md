模块采用 Maven 多模块拆分：`yudao-module-erp-api` 仅包含枚举常量（如 `ErpBizTypeEnum`、`ErrorCodeConstants`、`ApiConstants`）和包级说明，作为跨服务共享契约；`yudao-module-erp-server` 为可独立部署的 Spring Boot 应用（`ErpServerApplication`），按业务域 finance/product/purchase/sale/stock/statistics 划分 controller、service、dal（dataobject + mysql mapper + redis dao）三层目录。controller 层通过 `@RestController` + `@RequestMapping("/erp/...")` 暴露接口，使用 `@PreAuthorize("@ss.hasPermission(...)")` 做权限控制，并通过 `BeanUtils` 在 controller 内完成 DO→VO 转换；service 层实现领域逻辑（如库存增减校验、负库存开关），依赖 mapper 与同域 service 进行协作；dal 层基于 MyBatis-Plus，DO 与 Mapper 一一对应并按业务域子包组织，统计类查询使用 XML 映射文件。框架配置集中在 `framework/security/config/SecurityConfiguration`（放行 Swagger/Actuator/Druid/RPC 前缀）与 `framework/rpc/config/RpcConfiguration`（Feign 调用 `AdminUserApi`）。应用通过 `application.yaml` 引入 Nacos 配置，启用 Redis 缓存、XXL-JOB、Knife4j 文档与多租户能力。
