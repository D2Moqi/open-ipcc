- 模块间通过 XxxApi（定义于 -api 子模块）调用，禁止跨模块直引 Mapper/Service/DO
- 常量类统一使用 final class + private 构造，修饰符为 public static final，跨模块共享常量下沉至底层模块
- 业务异常使用 ServiceException + ErrorCodeConstants，外部调用异常需捕获记录日志而非向上抛出中断主流程
- ESL bgapi 命令统一通过 sendSyncMsg + extractReplyText 发送，命令前缀使用 EslHeaders 常量，响应判断使用 REPLY_OK_PREFIX/REPLY_ERR_PREFIX
- 前端枚举值必须与后端 Java 枚举保持一致，禁止在代码中使用数字/字符串字面量表示业务状态或类型
- ACL/配置变更后必须通过 ESL 异步向所有已连接 FS 实例下发 reloadxml + sofia profile external rescan 重载
