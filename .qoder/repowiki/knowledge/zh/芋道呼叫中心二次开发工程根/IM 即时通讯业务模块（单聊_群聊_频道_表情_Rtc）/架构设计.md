模块采用 Maven 多子模块结构：`yudao-module-im-api` 仅暴露空包作为对外 API 契约占位，`yudao-module-im-server` 为可独立部署的 Spring Boot 应用（入口 `ImServerApplication`，端口 48093），按领域划分为 controller/admin、service、dal（DO + MyBatis-Plus Mapper）、enums、framework/config、mq/consumer、job/rtc 等包。

分层边界清晰：controller 层按 admin/app 划分管理端与客户端接口；service 层以 `*Service` / `*ServiceImpl` 成对组织，每个领域（friend/group/face/message/channel/conversation/statistics/sensitiveword/rtc/websocket）一个子包；dal 层 DO 与 Mapper 一一对应并按相同领域目录镜像；enums 集中定义跨域常量（如 `ImContentTypeEnum` 统一编排 OpenIM 兼容的消息 type 段位）。配置通过 `ImProperties` 以嵌套 inner class（Friend/Group/Face/Message/Rtc）聚合到 `yudao.im.*` 前缀下，便于按子模块独立开关。

运行时依赖方向：controller → service → (mapper → MySQL) + (websocket → `WebSocketSenderApi` 推送) + (mq consumer 消费 system 模块事件) + (job 定时清理 RTC)。RTC 信令走 LiveKit Webhook 回调，媒体由 LiveKit SFU 承担，本模块仅负责 Token 签发与信令推送。Redis 用于 RTC 分布式锁（`ImRtcCallLockRedisDAO`）及键常量（`RedisKeyConstants`）。
