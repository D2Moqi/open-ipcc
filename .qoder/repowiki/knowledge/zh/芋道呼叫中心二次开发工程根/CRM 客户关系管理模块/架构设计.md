模块采用 Maven 多模块拆分：`yudao-module-crm-api` 仅暴露枚举常量（如 `CrmBusinessEndStatusEnum`、`CrmCustomerLevelEnum` 等）以及 `ApiConstants`、`ErrorCodeConstants`、`LogRecordConstants`、`DictTypeConstants` 等共享常量；`yudao-module-crm-server` 为可独立运行的 Spring Boot 应用（`CrmServerApplication`），按业务域划分 controller/service/dal/vo 目录，覆盖 clue、contact、business、contract、customer、product、receivable、performance、permission、followup、statistics 等子域。DAL 层基于 MyBatis-Plus，DO 与 Mapper 一一对应并按子域分包，复杂查询通过 `resources/mapper/*.xml` 的 XML SQL 实现；Redis 用于分布式编号生成（`CrmNoRedisDAO`）。框架扩展位于 `framework/`：自定义权限注解 `@CrmPermission` + AOP 切面、Excel 列选择函数、操作日志解析器（`operatelog/core/*ParseFunction`）、安全配置、RPC 配置等。定时任务集中在 `job/customer/CrmCustomerAutoPutPoolJob`。依赖方向严格单向：server → api → 基础设施 starter（security、mybatis、tenant、job、nacos 等），controller 仅依赖 service，service 依赖 dal，无循环引用（通过允许 bean 覆盖规避）。
