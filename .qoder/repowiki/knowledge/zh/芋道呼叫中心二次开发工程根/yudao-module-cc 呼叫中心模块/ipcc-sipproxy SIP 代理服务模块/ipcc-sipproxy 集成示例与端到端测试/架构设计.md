本模块为 ipcc-sipproxy 的演示与验证层，按用途划分为三个并列子工程：
- example-1-java：最小可用示例，仅通过 `@SpringBootApplication` 启动，完全依赖 ipcc-sipproxy 提供的默认 Bean（所有扩展点接口均使用 `@ConditionalOnMissingBean` 默认实现），配合 H2 内存库加载 schema.sql/data.sql seed 数据，并依赖 Redis 存储会话。
- example-2-java：扩展能力示例，排除 `DataSourceAutoConfiguration` 避免数据库自动配置，通过扫描 `cn.ipcc.example.ext` 包下的 14 个 `Custom*` 类（如 CustomAgentInfoProvider、CustomGatewayProvider、CustomSipAuthenticationProvider、CustomWsHandshakeAuthenticator 等）覆盖 sipproxy 的全部扩展点，所有数据硬编码在实现类中。
- example-jssip：基于 Vue3 + Vite + TypeScript + Element Plus + JsSIP 的前端软电话，暴露 ws-url/sip-domain/extension/password 输入框并通过 WebSocket 连接后端的 `/sipproxy/ws` 路径完成 SIP over WS 注册。
- test/test_registration.py：Playwright 无头 Chromium 端到端测试，遍历 BACKENDS 配置对 example-1-java（8081, token=test）与 example-2-java（8082, token=test-token）各执行 5 轮注册/签出流程，失败时截图到 test 目录并以 exit code 反馈结果。
依赖方向：test → example-jssip（浏览器 UI）→ example-*-java（SIP over WS 后端）→ ipcc-sipproxy 核心模块；示例之间相互独立，仅共享同一套 sipproxy 扩展点契约。
