- 每个示例工程以独立的 Spring Boot 启动类（Example1Application / Example2Application）作为入口，通过 `@SpringBootApplication` 注解启用自动装配。
- 扩展点实现统一采用 `CustomXxx` 命名规范并按功能域拆分到 `cn.ipcc.example.ext` 包下，每个文件对应一个 sipproxy 扩展接口。
- 前端交互元素通过 `data-testid` 属性标识，由 Playwright 测试脚本通过 `[data-testid=xxx]` 选择器定位，保证测试与 UI 解耦。
- 端到端测试将待测后端信息集中定义在 `BACKENDS` 列表中，通过外层循环遍历后端 × 轮次的方式复用同一轮测试逻辑。
