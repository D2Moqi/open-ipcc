- 每个扩展点在 `SipProxyAutoConfiguration` 中以独立 `@Bean` + `@ConditionalOnMissingBean(接口.class)` 形式注册默认实现，父工程只需提供同接口 Bean 即可无缝覆盖。
- 可选外部依赖（如 `JdbcTemplate`、`WsHandshakeAuthenticator`、`RedisMessageListenerContainer`）一律通过构造参数或 `ObjectProvider`/`@Autowired(required=false)` 注入，避免缺少依赖时启动失败。
- 条件装配统一使用 `@ConditionalOnProperty(prefix = "sipproxy.*", name = "...", havingValue = "...", matchIfMissing = true/false)` 组合，保证默认行为可预测且可通过配置显式关闭。
- 配置项集中在 `SipProxyProperties` 内以嵌套静态类（Sip/Websocket/Heartbeat/Cluster/Session）组织，统一使用 `@ConfigurationProperties(prefix = "sipproxy")` 绑定。
- 对 `SipProxyService` 等核心服务有强依赖的 Bean 放入内部 `@Configuration` 并以 `@ConditionalOnBean(SipProxyService.class)` 包裹，确保模块可在无核心服务时单独编译与部分装配。
