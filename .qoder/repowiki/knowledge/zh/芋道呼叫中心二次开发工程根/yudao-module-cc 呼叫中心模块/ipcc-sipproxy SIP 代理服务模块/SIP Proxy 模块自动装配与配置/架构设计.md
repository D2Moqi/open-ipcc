模块以 Spring Boot 3 的 `@AutoConfiguration` 机制组织，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明四个自动配置类：
- `SipProxyAutoConfiguration`：主装配入口，启用 `sipproxy.*` 配置属性并通过 `@ComponentScan("cn.ipcc.sipproxy")` 扫描业务组件；集中注册所有扩展点（AgentInfoProvider、FsNodeProvider、GatewayProvider、MessageSourceIdentifier、OutboundGatewayRewriter、SdpProcessor、IpWhitelist、SipRateLimiter、AuthenticationCallback、SipAuthenticationProvider、WsHandshakeAuthenticator、SipMessageInterceptor、TraceContext、SipMessageTransport）的默认实现，统一使用 `@ConditionalOnMissingBean` 允许父工程覆盖。
- `SipProxyWebSocketAutoConfiguration`：基于 JSR-356 配置 WebSocket 容器（8KB 缓冲、idleTimeout）、注册 `SipFrameReassembler`、`LocalWsSessionManager`、`SipHandshakeInterceptor` 和 `SipWebSocketHandler`，并将依赖 `SipProxyService` 的 Bean 放入内部 `@Configuration` 中以 `@ConditionalOnBean` 保护。
- `SipProxyClusterAutoConfiguration`：根据 `sipproxy.cluster.sender-type`（local/redis/rocketmq/rabbitmq/kafka）条件化注册 `WsMessageSender` 实现，并在存在 Redis 时装配 `RedisMessageListenerContainer`，同时 `@EnableScheduling` 启用定时任务。
- `SipProxySessionAutoConfiguration`：仅做 `StringRedisTemplate` 类路径存在性检查，作为会话存储依赖的 fail-fast 声明。
依赖方向单向向外：本模块只依赖 `api/`、`defaults/`、`core/`、`websocket/`、`cluster/` 包内的接口与实现，不反向被业务代码直接引用，全部通过 Spring 容器装配暴露。
