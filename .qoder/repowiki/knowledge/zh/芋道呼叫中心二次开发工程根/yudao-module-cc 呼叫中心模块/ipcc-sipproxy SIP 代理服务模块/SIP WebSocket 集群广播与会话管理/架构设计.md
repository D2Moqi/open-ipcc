模块按职责划分为两个子包：
- `cluster`：定义 `WsMessageSender` 接口及 `Local/Redis/Kafka/RocketMq/RabbitMqWsMessageSender` 五种实现，通过 Spring 配置 `sipproxy.cluster.sender-type` 在运行时切换；`ClusterBroadcastConsumer` 作为统一消费者注册到所选发送器的回调中，收到广播后按 `targetType`（USER/SESSION/ALL）分发到 `WsSessionManager` 推送给目标会话；`SipWsBroadcastMessage` 是跨 MQ 传输的 JSON 可序列化载体，含 `sourceInstance` 防环。
- `websocket`：以 `WsSessionManager` 接口抽象会话存储，`LocalWsSessionManager` 用 `ConcurrentHashMap` 维护 sessionId→session 与 username:domain→sessionId 双向映射；`SipWebSocketHandler` 继承 `TextWebSocketHandler` 负责连接生命周期（注册/注销）、调用 `SipFrameReassembler` 重组分片并委派 `SipProxyService`；`SipHandshakeInterceptor` 在握手阶段完成 token 校验（通过 `WsHandshakeAuthenticator` 扩展点）和 RFC 7118 子协议协商；`ZombieSessionCleaner` 基于 `lastActiveAt` 属性清理僵尸会话。
依赖方向：`cluster` → `websocket`（仅依赖 `WsSessionManager` 接口），`websocket` 不反向依赖 `cluster`，保证单实例与多实例场景可独立装配。
