本模块是 ipcc-sipproxy 的纯 API 层（仅含接口），作为 sipproxy 与父程序之间的 SPI 边界，遵循「sipproxy 不直接依赖父程序数据/业务层」的设计约束。按职责划分为若干子包：agent（AgentInfoProvider 提供坐席元数据）、authentication（SipAuthenticationProvider + AuthenticationCallback + WsHandshakeAuthenticator 实现可选的 Digest 认证覆盖）、gateway（GatewayProvider + MessageSourceIdentifier + OutboundGatewayRewriter 提供第三方 SIP 网关查询与重写）、fs（FsNodeProvider 提供在线 FreeSWITCH 节点列表）、interceptor（SipMessageInterceptor 在 WS↔SIP 转发前后插入 ESL 编排等自定义逻辑）、media（SdpProcessor 处理 INVITE/200 OK 中的 SDP）、security（IpWhitelist 与 SipRateLimiter 做来源 IP 白名单与请求速率限制）、trace（TraceContext 抽象链路追踪上下文）、transport（SipMessageTransport 抽象底层消息发送）。每个接口均标注为「可选实现」，由父程序通过 Spring 容器注入默认或自定义实现，使 sipproxy 在不了解父程序内部结构的前提下完成信令路由、认证、媒体协商与安全控制。
