- 每个扩展点以单一职责接口形式组织到独立子包下，并通过类级 Javadoc 明确说明调用时机、默认行为与返回值约定。
- 所有扩展点均设计为可选实现：未提供实现时 sipproxy 走内置默认逻辑（如放行、透传、不做限制），由调用方按需替换。
- 接口方法参数聚焦于 SIP 语义（extension/domain、sourceIp/method、message/targetHost/port/transport），避免引入父程序领域对象，保持 sipproxy 与父程序解耦。
- 对需要返回「不存在/拒绝」的场景统一采用 null 或 false 表示，由 sipproxy 侧根据业务场景决定后续处理（如 403 Forbidden、429 Too Many Requests）。
