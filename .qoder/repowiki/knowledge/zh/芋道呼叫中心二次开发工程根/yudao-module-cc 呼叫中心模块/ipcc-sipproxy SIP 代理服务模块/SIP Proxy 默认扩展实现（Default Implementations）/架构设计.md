本模块按功能域划分为 agent、authentication、fs、gateway、interceptor、media、security、trace、transport 等子包，每个子包对应 `cn.ipcc.sipproxy.api.*` 中的一个 SPI 接口，并提供以 `Default*` 或 `Noop*` 命名的默认实现类。
- 依赖方向单向：仅依赖 `sipproxy-api` 中的接口与 `sipproxy-support` 中的领域模型（如 AgentInfo、GatewayInfo、FsNodeInfo），不反向依赖任何业务实现，确保可被任意父工程覆盖。
- 数据访问层通过可选注入的 `JdbcTemplate` 查询 H2 seed 表（`sip_agent`、`sip_gateway`、`sip_fs_node`），当父程序未配置数据源导致 `jdbcTemplate == null` 时，统一退化为返回 `null` / 空列表，避免启动失败。
- 认证链路中 `DefaultSipAuthenticationProvider` 通过 `AgentInfoProvider` 获取坐席密码后本地计算 SIP Digest（MD5 HA1/HA2/response），将原内联校验逻辑下沉到扩展点。
- 安全与传输采用无副作用的 No-op 策略：`DefaultIpWhitelist` 全部放行、`DefaultSipMessageTransport` 交由 JAIN-SIP 内置 UDP/TCP 处理、`NoopSipMessageInterceptor` 所有拦截方法返回 false。
- 网关与 FS 节点查询使用 `BeanPropertyRowMapper` 或自定义 `RowMapper` 完成 JDBC ResultSet → 领域模型的映射，并对 BIGINT/String、可空整数字段做类型转换与空值保护。
