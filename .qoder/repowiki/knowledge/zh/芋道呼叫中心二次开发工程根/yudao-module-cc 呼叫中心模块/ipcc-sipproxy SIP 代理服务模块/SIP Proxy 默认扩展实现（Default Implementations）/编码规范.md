- 每个 SPI 接口在 defaults 下提供同名 `Default*` 或 `Noop*` 默认实现类，并通过 Spring Bean 注册以便父工程覆盖。
- 对可选外部依赖（如 `JdbcTemplate`）采用构造器注入并在方法入口处判空，缺失时记录 debug 日志并返回 `null` / 空集合以保证服务可启动。
- 数据库异常统一 catch 后记录 warn 日志并降级返回空结果，避免阻断 SIP 注册、路由、转发等核心链路。
- 日志输出统一采用 `[方法名][场景] key=value` 的方括号前缀格式，便于日志检索与告警匹配。
- JDBC 查询使用 `BeanPropertyRowMapper` 自动映射下划线列到驼峰字段，复杂类型（BIGINT→String、可空 Integer）通过自定义 `RowMapper` 显式处理。
- 网关状态约定与节点状态区分：`sip_gateway.status=0` 表示启用，`sip_fs_node.status=1` 表示启用，在查询 SQL 中显式过滤。
