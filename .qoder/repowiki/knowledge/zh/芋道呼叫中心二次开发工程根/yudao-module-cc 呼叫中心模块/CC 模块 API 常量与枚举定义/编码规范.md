- RPC 服务元信息（服务名、API 前缀、版本）集中在 `ApiConstants` 中以 `public static final` 字段声明，并复用 `RpcConstants.RPC_API_PREFIX` 拼接路径前缀。
- 业务错误码统一在 `ErrorCodeConstants` 接口中以 `ErrorCode` 实例静态字段声明，并按业务域分组注释划分，错误码采用 `1_060_xxx_xxx` 三段式编号。
- 业务枚举使用 Lombok `@Getter` + `@AllArgsConstructor` 注解，每个枚举项由 code（int）+ name（String）组成，便于序列化与展示。
- 常量与枚举均位于 `cn.iocoder.yudao.module.cc.enums` 单一包内，按职责拆分为多个独立类而非合并为一个巨型类。
