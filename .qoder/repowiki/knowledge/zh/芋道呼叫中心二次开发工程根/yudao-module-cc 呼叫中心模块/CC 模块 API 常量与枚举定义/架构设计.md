该模块为纯 API 契约层，仅包含 `cn.iocoder.yudao.module.cc.enums` 包下的常量与枚举类，无任何业务逻辑或网络实现。通过 Maven 打包为 jar 并被 yudao-module-cc 下其它子模块依赖。核心文件分工：`ApiConstants` 集中定义 RPC 服务名（`cc-server`）、API 前缀（基于 `RpcConstants.RPC_API_PREFIX + /cc`）和版本号；`ErrorCodeConstants` 以接口形式集中声明所有业务错误码，统一使用 `1_060_xxx_xxx` 号段；其余枚举（`SysVoiceTypeEnum`、`SysVoiceTtsTypeEnum`、`CallRouteStatusEnum`、`SysVoiceTtsTypeConstants`）描述语音类型、TTS 类型、呼叫路由状态等共享领域值。模块仅依赖 `yudao-common`，不引入任何框架或运行时依赖，确保作为跨模块共享契约的轻量性。
