本模块以 Maven 多子模块形式组织：ipcc-fs-esl 提供基于 Netty 的 FreeSWITCH ESL Inbound 客户端，ipcc-sipproxy 提供基于 JAIN-SIP 的 SIP over WebSocket 代理服务，两者均通过 Spring Boot AutoConfiguration 暴露为可复用组件；yudao-module-cc-api 定义跨子模块共享的枚举与常量；yudao-module-cc-server 作为唯一可执行应用，在启动时装配上述两个底层组件，并通过自定义扩展点（如 CcFsNodeProvider、CcGatewayProvider、CcAgentInfoProvider）将 FreeSWITCH 节点、网关与坐席信息注入到 SIP 代理中，同时承载 IVR 流程引擎、ESL 事件处理器、自动外呼调度以及管理后台 Controller/Service/Mapper 分层。三者之间的耦合边界由 cc_api 中的枚举/常量与 server 中对 ipcc-* 组件 SPI 接口的实现来约束，server 是唯一的编排层，其他子模块保持无状态可被外部工程直接引用。
