模块采用典型的三层结构：controller/admin/call 下每个业务实体（CallRoute、CallDisplay、CallDisplayPool、CallRecord、SysAgentGroup）对应一个 REST Controller，统一暴露 /cc/* 路径并提供 CRUD、分页、导出 Excel；service/call 中除各实体的 ServiceImpl 外，还包含两个核心业务能力——ConferenceService/ConferenceServiceImpl 通过 FsClient 调用 FreeSWITCH ESL 命令（conference create/kick/list、uuid_transfer、uuid_getvar）实现三方会议桥接，AutocallService/AutocallServiceImpl 通过 Redis 缓存任务上下文并以 originate+park 方式发起自动外呼，支持按被叫号码匹配 CallRoute 表选择 IVR 流程；dal/dataobject/call 下的 DO 类继承 TenantBaseDO 并通过 MyBatis-Plus 注解映射到 cc_call_route、cc_call_display_pool 等表。依赖方向单向向下：Controller → Service → DO，同时 Conference/Autocall 服务横向依赖 esl.client.FsClient、sipproxy.SipProxyGatewayService 及配置类 CcConfig/IpccSipProxyConfig，不反向依赖 controller。
