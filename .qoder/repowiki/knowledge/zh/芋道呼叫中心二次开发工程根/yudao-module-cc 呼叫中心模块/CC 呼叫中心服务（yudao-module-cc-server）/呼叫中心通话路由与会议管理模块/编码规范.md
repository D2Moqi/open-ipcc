- 每个业务实体在 controller/admin/call 下配套 RequestVO/RespVO/SaveReqVO，Controller 通过 BeanUtils.toBean 在 VO 与 DO 之间转换，并使用 @PreAuthorize("@ss.hasPermission('cc:*')") 进行接口级权限控制。
- Service 层统一拆分为接口与 Impl 类（如 ConferenceService/ConferenceServiceImpl、AutocallService/AutocallServiceImpl），并通过 @Resource 注入 FsClient、SipProxyGatewayService 等外部依赖。
- DO 类继承 TenantBaseDO 并使用 Lombok 的 @Data/@Builder/@NoArgsConstructor/@AllArgsConstructor 组合，主键通过 @TableId 配合 @KeySequence 声明序列名以兼容多数据库。
- FreeSWITCH 操作统一通过 FsClient 封装的常量 EslConstant（如 CONFERENCE、ORIGINATE、PARK、DEFAULT_CONTEXT）与 GatewayTypeEnum 枚举构造命令字符串，避免硬编码 ESL 指令。
- 自动外呼与会话状态通过 Redis 缓存（autocall:task:{taskId}，TTL 24h）保存任务上下文，并在挂断回调中恢复 TenantContextHolder 中的 tenantId 以保证 CDR 按租户隔离。
