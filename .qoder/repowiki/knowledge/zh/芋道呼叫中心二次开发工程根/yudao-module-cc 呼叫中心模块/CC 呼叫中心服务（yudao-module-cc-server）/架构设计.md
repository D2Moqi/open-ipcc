本模块是 CC 呼叫中心的可独立部署 Spring Boot 应用（入口 CcServerApplication），通过 @ComponentScan 同时扫描 cn.iocoder 与 cn.ipcc.sipproxy 两个包，将自研业务层与外部 ipcc-sipproxy Starter 装配到同一 ApplicationContext 中。各子模块按领域分层组织：controller/admin 提供管理后台 REST 接口，service 实现业务编排，dal 通过 MyBatis Mapper + XML 访问 MySQL；esl 子包封装 FreeSWITCH ESL 客户端、事件处理器工厂与呼叫流程编排，ivf_flow_engine 基于 Spring StateMachine + Redis 驱动 IVR 节点执行；websocket 子模块提供跨进程消息总线（本地/Redis/RabbitMQ/Kafka/RocketMQ 多后端），被 sip_proxy_integration、sys_agent_management 等模块用于坐席状态实时推送；fs_config_management 通过 xmlCurl 回调向 FS 动态返回 ACL/拨号计划配置；sip_proxy_integration 作为桥接层把 CC 侧的网关、节点、会话信息暴露给 ipcc-sipproxy。所有子模块共享 config/constant/enums/utils 中的基础配置与枚举，并通过 shared_infrastructure 提供的常量与工具类保持行为一致。
