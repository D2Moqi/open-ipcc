- 每个资源在 controller 中提供 create/update/delete/delete-list/get/page/list/export-excel 标准 CRUD 接口，并通过 @PreAuthorize("@ss.hasPermission('cc:sys-xxx:action')") 声明细粒度权限。
- 请求参数、响应对象、分页查询分别拆分为 SaveReqVO、RespVO、PageReqVO 三类 VO，Controller 仅负责参数校验与 BeanUtils.toBean 转换，不承载业务逻辑。
- Service 实现类统一使用 validateXxxExists(id) 私有方法在执行更新/删除前校验记录存在性，不存在则抛出 ErrorCodeConstants 中的异常。
- 对跨租户或全局查询的方法标注 @TenantIgnore，并通过 RedisTemplate 缓存域名列表与坐席在线状态，写操作后调用 clearDomainListCache() 失效缓存。
- 坐席在线状态变更时，先更新数据库再同步写入 Redis Hash（AGENT_CURRENT_STATUS_KEY），最后通过 CcWebSocketMessageSender 推送 AgentStatusData 到前端 WebSocket。
- DO 实体继承 TenantBaseDO 并使用 @TableName("cc_sys_xxx") + @KeySequence 注解，字段命名与数据库列一一对应，保持轻量 POJO 风格。
