模块采用标准的 Controller-Service-Mapper 三层结构：
- controller/admin/sys 下按资源划分四个 REST 控制器（SysAgentController、SysPhoneLocationController、SysVoiceEngineController、SysVoiceFileController），统一以 /cc/sys-* 前缀暴露，每个资源配套 vo/ 下的 PageReqVO/SaveReqVO/RespVO。
- service/sys 下对应实现类通过 MyBatis-Plus 的 Mapper 访问数据库，并复用框架的 PageResult/PageParam 完成分页；复杂业务（如坐席）在 Service 层完成校验、缓存清理、跨服务调用与消息推送。
- dal/dataobject/sys 定义 DO 实体（SysAgentDO、SysPhoneLocationDO、SysVoiceEngineDO、SysVoiceFileDO），均继承 TenantBaseDO 支持多租户，使用 @TableName/@KeySequence 映射 cc_sys_* 表。
依赖方向单向向下：Controller → Service → Mapper → DB；同时横向依赖 system 模块的 AdminUserApi 获取用户信息，以及同模块内的 call/sipproxy/websocket 子模块完成坐席组、网关、WebSocket 状态广播等协作。
