- 所有可插拔的消息发送器均实现 `CcWebSocketMessageSender` 接口并继承 `AbstractCcWebSocketMessageSender`，由基类统一完成 Session 查找与 JSON/SIP 消息包装，子类只需实现 `doSend`。
- 多后端实现通过内部静态 `@Configuration` 类 + `@ConditionalOnProperty(prefix = "cc.websocket", name = "sender-type", havingValue = "...")` 条件装配，避免引入无关依赖。
- 每条消息统一封装为 `JsonWebSocketMessage`（含 type/content）或直接透传 SIP 原始报文，由 `AbstractCcWebSocketMessageSender.doSend` 集中判断是否走 SIP 分支。
- WebSocket 连接生命周期钩子（建立/关闭/错误）统一通过 `WebSocketSessionHandlerDecorator` 装饰器处理，并在断开时调用 `SysAgentService` 更新坐席离线状态。
- 配置项集中在 `CcWebSocketProperties` 并使用 `@Validated` 校验必填字段（path、senderType、心跳间隔/超时均为正数）。
- 消息体采用 `CcWebSocketMessagePayload`（sessionId/timestamp/event/data）作为前后端契约，事件类型通过 `CcWebSocketEventEnum` 枚举集中管理。
