- 事件处理器统一继承 `AbstractFsEslEventHandler`，并通过 SDK 的 `@EslEventName` 注解声明所处理的 FS 事件名，由 SDK 自动收集注册。
- 呼叫流程处理器统一继承 `FsAbstractCallProcess`，并通过 `FsEslProcessFactory` 配合 `@EslProcessName` 注解按 `ProcessEnum` 进行运行时路由。
- xml_curl 回调处理器通过 `FsXmlCurlEventStrategyFactory` + `@XmlCurlEventName` 注解实现策略模式，新增类型只需新增策略 Bean。
- TTS 扩展点采用 `AbstractFileTtsHandler` 抽象基类 + `FileTtsService` 接口，具体引擎通过实现 `tts(text, engine, consumer)` 并以 `Consumer<File>` 回调输出音频文件。
- 所有对外部 FS 节点的命令发送均通过 `FsClient` 门面方法封装，避免业务代码直接操作底层 `EslConnectionManager`。
- 对 FS 异步命令（originate、uuid_kill 等）统一使用 `sendAsyncMsg` 走 bgapi 发送，结果通过 BACKGROUND_JOB 事件异步返回，避免阻塞调用线程。
