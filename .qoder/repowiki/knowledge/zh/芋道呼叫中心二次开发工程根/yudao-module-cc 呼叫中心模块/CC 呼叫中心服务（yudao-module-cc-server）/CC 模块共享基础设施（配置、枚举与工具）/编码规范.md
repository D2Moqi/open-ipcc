- 配置类使用 `@Component` + `@ConfigurationProperties(prefix = "...")` 声明为 Spring Bean，并通过嵌套静态 `@Data` 类组织层级配置项（如 `FreeswitchConfig`、`SipConfig`）。
- 业务枚举采用 Lombok `@Getter` + `@AllArgsConstructor` 构造，并为带整型标识的枚举实现 `ArrayValuable<Integer>` 并提供 `ARRAYS` 静态数组以支持前端下拉与校验。
- FreeSWITCH 相关枚举（如 `AppEnum`）以「常量名(字符串, 英文描述)」形式定义，并提供 `instance(String)` 静态查找方法完成名称到枚举的反查。
- 工具类设计为 `final` 类 + 私有构造函数，仅提供 `static` 方法，保持无状态与线程安全（如 `XmlCurlUtil`）。
- HTTP 请求参数解析时先收集为 `Map<String,String>` 再经 FastJSON 序列化为目标 DTO，并将原始 Map 回填至 `metadata` 字段以保留未映射键。
