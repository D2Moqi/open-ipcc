本模块按职责划分为三个并列子包，作为 cc-server 的共享底座：
- `config`：通过 Spring Boot `@ConfigurationProperties` + `@Component` 将外部化配置注入为 Bean，`CcConfig` 绑定 `cc.*`（FreeSWITCH 录音、编码、ESL 线程池等），`IpccSipProxyConfig` 绑定 `sipproxy.*`（SIP 代理公网 IP/端口），供上层 SIP 网关与媒体处理组件消费。
- `enums`：集中定义 FreeSWITCH dialplan 应用命令（`AppEnum`，900+ 项）、SIP 传输协议（`SipTransportProtocolEnum`）、SIP 代理网关认证/主叫号码/参数类型等枚举；其中带数值标识的枚举统一实现框架 `ArrayValuable<Integer>` 并暴露 `ARRAYS` 静态数组，便于校验与下拉选项生成。
- `utils`：提供无状态的纯函数式工具，如 `XmlCurlUtil` 将 FreeSWITCH `xml_curl` 回调的 `HttpServletRequest` 参数解析为 `FsXmlCurl` DTO，并通过 FastJSON 中转保留原始 metadata。
依赖方向单向向外：本模块仅依赖 Spring Boot、Lombok、FastJSON 及框架公共接口（`ArrayValuable`），不被业务层反向依赖配置细节，仅以 Bean/枚举/工具方法形式被调用。
