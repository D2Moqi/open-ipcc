- 每个业务实体均拆分为 DO（数据库映射）、VO（请求/响应参数）、Service 接口与实现类、Controller 控制器四层结构。
- Controller 方法统一返回 `CommonResult<T>`，并使用 `@PreAuthorize("@ss.hasPermission('cc:autocall-task:*')")` 进行权限控制。
- 数据对象继承 `TenantBaseDO` 并使用 Lombok 的 `@Data/@Builder/@NoArgsConstructor/@AllArgsConstructor` 注解组合。
- Service 接口定义清晰的方法契约，实现类通过 `BeanUtils.toBean` 在 Controller 层完成 VO ↔ DO 转换。
- 对外部回调（FS 挂断事件）通过实现框架定义的 `AutocallResultCallback` 并以 `@Primary` 注册，保证可被替换。
- 定时任务使用 `@Scheduled(fixedDelay = 30000, initialDelay = 30000)` 包裹 try-catch 仅记录日志，避免异常中断下一次调度。
