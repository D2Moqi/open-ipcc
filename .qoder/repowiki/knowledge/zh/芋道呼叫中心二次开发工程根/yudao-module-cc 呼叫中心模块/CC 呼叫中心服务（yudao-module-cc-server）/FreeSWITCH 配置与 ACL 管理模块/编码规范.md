- 每个实体对应一组 VO（SaveReqVO/PageReqVO/RespVO）、Controller、Service 接口与实现、DO，命名遵循 FsXxx* 前缀。
- Controller 统一返回 CommonResult，并使用 BeanUtils.toBean 在 DO 与 RespVO 之间转换。
- CRUD 方法通过 @PreAuthorize("@ss.hasPermission('cc:fs-xxx:action')") 进行细粒度权限控制。
- 分页查询接收 PageReqVO，返回 PageResult<DO>，导出 Excel 时设置 pageSize=PAGE_SIZE_NONE 拉取全量数据。
- DO 继承 TenantBaseDO 并使用 MyBatis-Plus 注解标注表名、主键序列与字段映射。
- 对外部系统回调接口（xmlCurl）使用 @PermitAll 与 @TenantIgnore 跳过认证与租户过滤。
