模块采用 controller/service/dal(dataobject) 三层结构：
- controller/admin/fs/：暴露 REST API，FsConfigController/FsAclController/FsDialplanController 提供标准增删改查与分页、导出 Excel；FsXmlCurlController 提供 /cc/fs/curl/api 的 GET/POST 端点，供 FreeSWITCH 通过 xml_curl 协议回调。
- service/fs/：定义 FsXxxService 接口及 FsXxxServiceImpl 实现，封装业务逻辑（如 FsConfigServiceImpl 提供 getOnlineFsNodesFromCache 获取在线 FS 节点列表）。
- dal/dataobject/fs/：使用 MyBatis-Plus 注解（@TableName/@TableId/@KeySequence）映射 cc_fs_config、cc_fs_acl、cc_fs_dialplan 等表，DO 继承 TenantBaseDO 支持多租户。
- 权限控制通过 @PreAuthorize("@ss.hasPermission('cc:fs-xxx:...')") 按资源粒度授权；xmlCurl 回调接口使用 @PermitAll + @TenantIgnore 绕过鉴权与租户隔离。
- 事件分发：FsXmlCurlServiceImpl 通过 FsXmlCurlEventStrategyFactory 根据 section/keyValue 路由到具体策略，将请求转换为 FreeSWITCH 可消费的 XML 文档。
