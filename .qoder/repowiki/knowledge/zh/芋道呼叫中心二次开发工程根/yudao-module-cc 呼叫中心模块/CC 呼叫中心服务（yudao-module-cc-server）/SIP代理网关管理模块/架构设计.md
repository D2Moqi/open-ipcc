模块遵循标准三层架构：controller层在 `cn.iocoder.yudao.module.cc.controller.admin.sipproxy` 下暴露 `/cc/sip-proxy-gateway` REST接口，使用 `@PreAuthorize` 按 `cc:sip-proxy-gateway:*` 权限控制；service层在 `sipproxy` 包中定义 `SipProxyGatewayService` 接口及 `SipProxyGatewayServiceImpl` 实现，通过 `SipProxyGatewayMapper` 访问数据库（MyBatis-Plus），并通过 `FsClient` 获取已连接的FreeSWITCH地址以做回环冲突校验；dataobject层在 `dal/dataobject/sipproxy` 下定义 `SipProxyGatewayDO`，映射表 `cc_sipproxy_gateway`，继承 `TenantBaseDO` 支持多租户。读路径对启用列表使用 Spring Cache + Redis（`RedisKeyConstants.SIP_PROXY_GATEWAY_ENABLED_LIST`）缓存，写操作通过 `@CacheEvict` 失效；跨租户读取方法标注 `@TenantIgnore`。VO层拆分 SaveReqVO/PageReqVO/RespVO，由 Controller 经 BeanUtils.toBean 转换后返回。
