- Controller每个接口均使用 @Operation 描述、@PreAuthorize 按 cc:sip-proxy-gateway:xxx 权限控制，并以 CommonResult.success 统一包装返回值。
- Service写操作方法通过 @CacheEvict(cacheNames = RedisKeyConstants.SIP_PROXY_GATEWAY_ENABLED_LIST, allEntries = true) 在创建、更新、删除时主动清空启用网关缓存。
- 跨租户只读方法如 getEnabledListByCache、getGatewayByAddress 使用 @TenantIgnore 注解绕过租户过滤。
- 请求参数与响应对象分离为独立的 VO（SaveReqVO、PageReqVO、RespVO），Controller 通过 BeanUtils.toBean 在 DO 与 VO 之间转换。
- 业务校验抽取为私有方法如 validateNameUnique、validateAuthInfo、validateAddressNotConflictWithFs，并通过 exception(ErrorCodeConstants.*) 抛出统一业务异常。
