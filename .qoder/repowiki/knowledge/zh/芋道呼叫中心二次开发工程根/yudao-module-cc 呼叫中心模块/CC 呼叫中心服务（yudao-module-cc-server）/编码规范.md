- 每个业务域（call/autocall/fs/sys/flow/sipproxy）均遵循 controller → service → dal(dataobject + mysql mapper) 的分层结构，VO/DO/Mapper 一一对应。
- ESL 事件处理采用注解路由（EslProcessName/EslRouteName）+ 工厂模式（FsEslProcessFactory/FsEslRouteFactory）分发到具体 Handler。
- WebSocket 消息发送通过 CcWebSocketMessageSender 抽象及 Kafka/Redis/RabbitMQ/RocketMQ/Local 多实现切换，调用方不感知底层传输。
- 配置项集中在 config 包下的 XxxConfig/XxxProperties 类，并通过 application.yaml 按环境区分。
- 枚举集中定义在 enums 包，SIP/FS 相关协议值使用专用枚举类型（如 SipTransportProtocolEnum、FsHangupCauseEnum）。
