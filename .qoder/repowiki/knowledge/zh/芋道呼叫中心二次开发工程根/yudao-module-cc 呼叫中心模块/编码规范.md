- 所有可复用能力均以 Spring Boot AutoConfiguration + META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports 方式对外暴露，便于父工程按需启用
- 业务常量、错误码与枚举统一集中在 yudao-module-cc-api 中定义，各子模块通过依赖引入而非重复声明
- 对 FreeSWITCH 与 SIP 代理的集成采用 SPI 扩展点模式（如 FsNodeProvider、GatewayProvider、AgentInfoProvider），默认实现在 defaults 包，业务实现放在 server 的对应包下
- ESL 事件处理遵循 handler/factory 分层：具体事件处理器继承 AbstractFsEslEventHandler，由 FsEslProcessFactory/FsEslRouteFactory 按 process/route 维度分发
