- 所有网关横切逻辑以 `@Component` 注解的类实现 `GlobalFilter` 与 `Ordered` 接口，并通过 `getOrder()` 明确指定执行顺序（如鉴权 -100、日志最高优先级）。
- 下游服务路由统一使用自定义 `grayLb://` 协议指向服务名，并在路由上附加 `RewritePath=/admin-api/*/v3/api-docs, /v3/api-docs` 以统一 Swagger 文档路径。
- 对下游服务的调用统一通过 `WebClient.builder().filter(lbFunction)` 构造，避免引入 Feign 以保持纯响应式链路。
- 全局异常处理统一实现 `ErrorWebExceptionHandler`，将异常转换为统一的 `CommonResult` 结构返回给前端。
- JSON 序列化通过 `Jackson2ObjectMapperBuilderCustomizer`、`Module` 与 `CodecCustomizer` 三处同时定制，确保 WebFlux 编解码器与 `JsonUtils` 行为一致。
- 跨组件共享的上下文（登录用户、租户ID、客户端IP、traceId）通过 `SecurityFrameworkUtils`、`WebFrameworkUtils`、`SkyWalkingTraceUtils` 等工具类封装存取，而非直接在过滤器中操作 Exchange。
