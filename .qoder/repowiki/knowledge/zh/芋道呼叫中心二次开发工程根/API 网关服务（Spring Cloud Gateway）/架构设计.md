模块以 `GatewayServerApplication` 为启动入口，采用 Spring Boot + WebFlux 响应式架构，核心能力通过实现 `GlobalFilter` 的过滤器链组织：
- `filter/security/TokenAuthenticationFilter`：在请求进入下游前校验 OAuth2 Token，通过 `WebClient` + `ReactorLoadBalancerExchangeFilterFunction` 调用 system 服务的 checkToken 接口，并将解析后的 `LoginUser` 写入请求头透传；使用本地缓存减少远程调用。
- `filter/logging/AccessLogFilter`：包装 `ServerHttpRequestDecorator` 与 `ServerHttpResponseDecorator` 读取并缓存请求/响应体，记录 traceId、用户信息、耗时等指标。
- `filter/grey/GrayReactiveLoadBalancerClientFilter` 与 `GrayLoadBalancer`：复制并重写 Spring 内置的 `ReactiveLoadBalancerClientFilter`，将 `lb://` 替换为自定义的 `grayLb://` 协议，实现按灰度策略选择后端实例。
- `filter/cors/CorsFilter`：提供跨域支持。
- `handler/GlobalExceptionHandler`：实现 `ErrorWebExceptionHandler`，将异常统一转换为 `CommonResult` 返回，优先级高于默认处理器。
- `jackson/GatewayJacksonAutoConfiguration`：通过 `Jackson2ObjectMapperBuilderCustomizer`、`Module` 与 `CodecCustomizer` 统一 WebFlux 编解码器的序列化规则（LocalDateTime 转时间戳、Long 转 Number 等）。
- `util/` 提供 `SecurityFrameworkUtils`、`WebFrameworkUtils`、`SkyWalkingTraceUtils`、`EnvUtils` 等横切工具。
路由全部集中在 `application.yaml` 的 `spring.cloud.gateway.routes` 中，按业务域（system/infra/member/bpm/pay/product/promotion/trade/statistics/erp/crm/ai/iot/mes/wms/im/cc）划分，并通过 `RewritePath` 统一 Swagger 文档路径；同时配置 `knife4j gateway routes` 聚合各服务 API 文档。注册中心与配置中心使用 Nacos（`spring-cloud-starter-alibaba-nacos-discovery/config`），监控集成 SkyWalking WebFlux APM。
