- 每个业务域在 api 与服务端均按子包拆分（spu/sku/category/comment/favorite/history/property/brand），Controller、Service、DO、Mapper、VO、DTO 一一对应。
- 跨模块 RPC 通过 `@FeignClient(name = ApiConstants.NAME)` 定义接口，路径前缀统一取自 `ApiConstants.PREFIX`，并在服务端以 `*ApiImpl` 实现。
- Controller 统一返回 `CommonResult<T>`，使用 `@PreAuthorize("@ss.hasPermission('product:*')")` 做权限控制，并通过 `@Validated` + JSR303 校验请求 VO。
- 数据转换集中放在 `convert/*` 下的 MapStruct `*Convert` 接口，Controller/Service 通过 `BeanUtils.toBean` 或 Convert.INSTANCE 进行 DO↔VO 映射。
- 业务异常通过 `ServiceExceptionUtil.exception(ErrorCodeConstants.*)` 抛出，错误码集中在 `enums/ErrorCodeConstants.java` 中统一定义。
- 可写操作在 ServiceImpl 上使用 `@Transactional(rollbackFor = Exception.class)` 包裹，跨表更新（如 SPU+SKU）在同一事务内完成。
