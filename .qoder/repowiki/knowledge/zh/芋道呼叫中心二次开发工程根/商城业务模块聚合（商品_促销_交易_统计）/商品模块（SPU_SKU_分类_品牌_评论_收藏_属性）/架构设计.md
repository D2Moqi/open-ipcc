模块采用标准的 Dubbo/Feign 微服务分层：
- yudao-module-product-api 仅包含 Feign 接口（`api/*`）、跨模块共享 DTO（`api/*/dto`）与常量枚举（`enums`），依赖 `yudao-common`、OpenFeign、springdoc-openapi，作为被其他模块调用的契约包。
- yudao-module-product-server 是独立 Spring Boot 应用（`ProductServerApplication`，端口 48100，应用名 `product-server`），内部按业务域划分子包：controller/admin 与 controller/app 分别面向管理后台与 C 端；service 层以 `*Service`/`*ServiceImpl` 形式封装事务与业务编排；dal/dataobject 对应 MyBatis-Plus 实体，dal/mysql 为 Mapper；convert 使用 MapStruct Convert 完成 DO↔VO 转换；framework 下含 RpcConfiguration 与 SecurityConfiguration 等本地配置。
- 依赖方向严格单向：controller → service → mapper，跨模块调用通过 product-api 中的 `@FeignClient(name = ApiConstants.NAME)` 声明，服务名与 `application.yaml` 中 `spring.application.name` 保持一致。
- 多租户、Redis 缓存、XXL-JOB、Knife4j/Swagger、MyBatis-Plus 等能力由父工程 starter 注入，本模块通过 `application.yaml` 的 `config.import` 引入 Nacos 配置并启用 `allow-circular-references` 以支持三层架构下的循环依赖。
