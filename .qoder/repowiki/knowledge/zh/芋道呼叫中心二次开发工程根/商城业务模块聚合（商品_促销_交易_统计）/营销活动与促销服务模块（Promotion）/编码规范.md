- RPC 接口集中在 `promotion-api` 模块下按活动域分包（如 coupon、seckill），接口使用 `@FeignClient(name = ApiConstants.NAME)` 并通过 `PREFIX = ApiConstants.PREFIX + "/xxx"` 拼接路径。
- `promotion-server` 中的 `api/*ApiImpl` 以 `@RestController` 实现对应 API 接口，仅做参数校验与 DTO 转换后委派给 `service/*Service`，不写业务逻辑。
- 数据层统一采用 DO（DataObject）+ Mapper 模式，DO 放在 `dal/dataobject/<domain>`，Mapper 放在 `dal/mysql/<domain>`，一一对应。
- 对象转换通过 `convert/<domain>/<Entity>Convert` 类完成，由 Controller/Service 调用 BeanUtils 或 MapStruct 风格的 convert 方法在 VO/DTO/DO 之间转换。
- 枚举常量集中放置在 `enums/<domain>` 包下（如 `CouponStatusEnum`、`BargainRecordStatusEnum`），公共枚举（活动状态、类型、条件类型等）放在 `enums/common`。
- 定时任务统一放在 `job/<domain>` 包内，使用 `@XxlJob("jobName")` 配合 `@TenantJob` 多租户注解声明，执行方法返回统计字符串。
