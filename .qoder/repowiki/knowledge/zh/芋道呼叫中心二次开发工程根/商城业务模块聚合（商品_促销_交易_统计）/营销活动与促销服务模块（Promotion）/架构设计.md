模块按 yudao 微服务规范拆分为两个 Maven 子工程：
- `yudao-module-promotion-api`：纯 API 契约包，仅依赖 `yudao-common`、`springdoc-openapi`、`spring-boot-starter-validation` 和可选的 `spring-cloud-starter-openfeign`；通过 `@FeignClient(name = ApiConstants.NAME)` 暴露各活动类型的 RPC 接口（bargain/combination/coupon/discount/point/reward/seckill），并在 `enums/ApiConstants.java` 中集中定义服务名 `promotion-server`、统一前缀 `/promotion` 与版本。
- `yudao-module-promotion-server`：可独立部署的 Spring Boot 应用（`PromotionServerApplication`，端口 48101），依赖 system/infra/product/trade/member 等其它业务模块 API，实现所有 RPC 接口（`api/*ApiImpl` 以 `@RestController` 暴露给 Feign 调用），同时提供 `controller/admin`（管理后台）与 `controller/app`（C端）两套 HTTP 控制器。

内部分层遵循 controller → service → dal（DO + Mapper）+ convert 的标准三层结构，每个活动域（bargain/combination/coupon/diy/seckill 等）均拥有独立的包目录与 DO/Mapper/Service/Controller/Convert 对应文件。跨领域能力通过 starter 注入：`yudao-spring-boot-starter-rpc` 启用 Feign 消费方、`yudao-spring-boot-starter-security` 提供安全、`yudao-spring-boot-starter-mybatis` 提供 MyBatis-Plus、`yudao-spring-boot-starter-job` 集成 XXL-Job（`job/*Job`）、`yudao-spring-boot-starter-mq` 提供 MQ 消费者/生产者骨架。配置通过 `application.yaml` 引入本地与 Nacos 配置，服务名 `promotion-server` 与 `ApiConstants.NAME` 保持一致以实现注册中心发现。
