- 每个业务域拆分为 *-api 与 *-server 两个 Maven 模块，API 端只暴露 Feign 接口、DTO 与枚举，实现全部放在 server 端
- 跨域调用统一通过 Feign 客户端调用对方 *-api 中定义的接口，禁止直接依赖对方 server 代码
- Controller 按 admin（管理后台）与 app（客户端）双目录划分，同一领域下功能一一对应
- 领域内实体转换统一抽取到 convert/* 下的 XxxConvert 类，Service 层不直接操作 DTO/DO 映射
- 数据库访问按 dataobject 与 mysql mapper 分目录组织，mapper XML 置于 resources/mapper 对应子目录
- 框架能力（RPC、安全等）统一收敛在 framework/rpc 与 framework/security 子包下
