模块采用标准的 API + Server 双工程拆分：`yudao-module-statistics-api` 仅暴露枚举（如 `TimeRangeTypeEnum`）供其他模块引用；`yudao-module-statistics-server` 是独立 Spring Boot 应用（入口 `StatisticsServerApplication`），通过 Nacos 注册发现与配置中心集成。

内部按业务域（trade/product/member/pay/infra）划分 controller → service → dal 三层，每层再细分子包并配套 VO/BO/DO/Mapper/XML：
- Controller 位于 `controller/admin/{domain}`，统一以 `/statistics/{domain}` 路由暴露，使用 `@PreAuthorize("@ss.hasPermission(...)")` 做权限控制，返回 `CommonResult` 并通过 `DataComparisonRespVO` 封装同比/环比对比。
- Service 层聚合多个下游统计子服务（如 `TradeStatisticsServiceImpl` 组合 `TradeOrderStatisticsService`、`AfterSaleStatisticsService`、`BrokerageStatisticsService`、`PayWalletStatisticsService`），并使用 `StopWatch` 记录各阶段耗时。
- DAL 层基于 MyBatis Plus（`BaseMapperX`）+ XML 自定义 SQL，DO 对应统计表（如 `TradeStatisticsDO`、`ProductStatisticsDO`），Mapper 提供时间区间查询方法。
- 转换层 `convert/{domain}` 使用 MapStruct Convert 实例在 DO/BO/VO 之间映射。
- 定时任务位于 `job/{domain}`，通过 XXL-JOB 的 `@XxlJob` 注解定义（如 `productStatisticsJob`、`tradeStatisticsJob`），并以 `@TenantJob` 支持多租户隔离执行。
- 依赖方向单向：server 依赖 `yudao-module-statistics-api` 以及 trade/product/member/pay/promotion 等其它模块的 API，用于读取原始业务数据进行聚合统计。
