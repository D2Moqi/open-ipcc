- 跨模块 RPC 通过 `@FeignClient(name = ApiConstants.NAME)` 在 api 工程中声明接口，并在 server 工程中以同名 `*Impl` 类用 `@RestController` 实现，形成契约-实现分离。
- 领域枚举集中放在 `enums/{domain}` 子包下（order/aftersale/brokerage/delivery/notify），并以 `*Enum.java` 命名，统一承载状态码与业务常量。
- Service 层按业务域拆分子包，每个域包含 `Service` 接口与 `ServiceImpl` 实现，复杂写操作通过 `@Transactional(rollbackFor = Exception.class)` 包裹。
- 订单生命周期扩展点通过 `TradeOrderHandler` 接口 + 默认方法 + `List<TradeOrderHandler>` 注入的方式实现，新增活动类型只需新增 Handler 实现即可被编排调用。
- 价格计算采用策略模式：`TradePriceService` 聚合多个 `*PriceCalculator`（优惠券、拼团、砍价、积分、运费等），各计算器独立实现并按规则组合计算。
- DO 到 VO/DTO 的转换统一放在 `convert/{domain}/*Convert.java` 中，使用 MapStruct INSTANCE 静态实例进行对象映射。
- 定时任务统一使用 `@XxlJob` 注解配合 `@TenantJob` 多租户包装，任务名遵循 `{业务}{动作}Job` 命名规范。
