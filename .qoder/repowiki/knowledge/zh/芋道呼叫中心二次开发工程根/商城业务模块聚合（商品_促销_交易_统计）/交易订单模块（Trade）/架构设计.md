模块采用 `api` + `server` 双子工程拆分：`yudao-module-trade-api` 仅暴露 Feign 接口（如 `TradeOrderApi`）、DTO 与领域枚举（order/aftersale/brokerage/delivery/notify），供其他模块通过 OpenFeign 调用；`yudao-module-trade-server` 为 Spring Boot 应用，按领域垂直分层组织：`controller/admin` 与 `controller/app` 分别面向管理与客户端入口，`service` 下按 aftersale/order/cart/delivery/brokerage/price/message 划分业务域，每个域包含 Service 接口与 Impl、BO、Handler/Calculator 扩展点；`dal` 层以 DO+Mapper 对应 MySQL，并通过 `redis` 子包管理分布式编号生成；`framework` 提供跨领域横切能力（订单 AOP 日志、配送快递客户端、RPC 配置、安全配置）；`job` 使用 XXL-Job 的 `@XxlJob` + `@TenantJob` 实现订单自动取消/收货/评论、佣金解冻等定时任务。依赖方向严格单向：server → api → 其他模块的 *-api（product/pay/promotion/member/system），通过 RPC 协作完成下单、支付、促销、会员地址等跨域流程。
