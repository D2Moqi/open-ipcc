本模块由四个相互独立的 Spring Boot Starter 组成，每个 starter 通过 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册自动配置类，以 `@AutoConfiguration` + `@ConditionalOnProperty/@ConditionalOnClass` 的方式按需装配：
- `yudao-spring-boot-starter-biz-data-permission`：基于 MyBatis Plus 的 `DataPermissionInterceptor` 实现 SQL 级数据权限，通过 `DataPermissionRuleFactory` 聚合多条 `DataPermissionRule`（内置部门规则），由 AOP 切面在方法执行前将 `DataPermission` 注解信息写入 `DataPermissionContextHolder`，RPC 调用则通过 `DataPermissionRpcWebFilter`/`DataPermissionRequestInterceptor` 透传上下文。
- `yudao-spring-boot-starter-biz-tenant`：以 `TenantContextHolder`（基于 `TransmittableThreadLocal`）贯穿请求链路，通过 Web Filter、MVC Interceptor、MyBatis `TenantLineInnerInterceptor`、Redis CacheManager、以及 Redis/RabbitMQ/RocketMQ/XxlJob 的条件化 MQ/Job 拦截器完成多租户上下文注入与 SQL 改写；支持 `@TenantIgnore` 注解排除特定接口。
- `yudao-spring-boot-starter-biz-ip`：纯工具型 starter，启动时从 classpath 加载 `ip2region.xdb` 构建内存 Searcher，提供 IP→地区编号及地区对象查询能力。
- `yudao-spring-boot-starter-excel`：封装 FastExcel 读写，提供列宽自适应、下拉框、字典转换等 WriteHandler/Converter，并附带基于字典的 Bean Validation 约束 `@InDict` 及其 Validator。
依赖方向：各 starter 仅依赖框架层（common/mybatis/redis/web/security）与第三方库，彼此之间无直接依赖，可单独引入。
