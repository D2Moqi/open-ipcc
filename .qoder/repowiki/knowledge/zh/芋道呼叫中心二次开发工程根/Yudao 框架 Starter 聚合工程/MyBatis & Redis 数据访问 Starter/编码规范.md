- 自动配置类统一以 `Yudao*AutoConfiguration` 命名并通过 `@AutoConfiguration(before = ...)` 指定加载顺序，确保覆盖第三方 Starter 的默认 Bean。
- 实体基类 `BaseDO` 通过 `@TableField(fill=...)` 与 `MetaObjectHandler` 实现创建时间、更新时间、创建者、更新者、逻辑删除字段的自动填充。
- 对外的数据访问接口集中在 `BaseMapperX` 中以 default 方法形式提供分页、单条、批量、锁行等通用 CRUD 能力，业务 Mapper 只需继承该接口。
- Redis 序列化统一通过 `buildRedisSerializer()` 构建，KEY 使用 String 序列化，VALUE 使用注入 `JavaTimeModule` 的 Jackson JSON 序列化。
- 条件装配广泛使用 `@ConditionalOnProperty` 控制可选功能开关（如 ID 自增策略、Druid 监控过滤器、懒初始化等）。
