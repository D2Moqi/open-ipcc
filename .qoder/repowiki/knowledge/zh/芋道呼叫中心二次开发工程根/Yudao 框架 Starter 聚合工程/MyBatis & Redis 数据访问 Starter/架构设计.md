模块由两个独立的 Spring Boot Starter 组成：
- yudao-spring-boot-starter-mybatis：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `YudaoDataSourceAutoConfiguration`、`YudaoMybatisAutoConfiguration`、`YudaoTranslateAutoConfiguration` 三个自动配置类。其中 `YudaoMybatisAutoConfiguration` 在 `MybatisPlusAutoConfiguration` 之前执行，启用 `@MapperScan`、`PaginationInnerInterceptor`、`DefaultDBFieldHandler`（自动填充 createTime/updateTime/creator/updater/deleted），并通过 `IdTypeEnvironmentPostProcessor` 根据 DbType 动态装配主键生成器；`BaseDO` 作为所有实体基类，配合 `TableField(fill=...)` 和 `@TableLogic` 实现统一审计与逻辑删除；`BaseMapperX` 继承 MPJBaseMapper，扩展分页查询、selectOne/selectList/selectCount/batch 等默认方法；`core/type` 下提供 JSON、集合、加解密等 TypeHandler；`core/query` 提供 LambdaQueryWrapperX/MPJLambdaWrapperX 等包装器；`translate` 子包集成 Easy-Trans 翻译能力。
- yudao-spring-boot-starter-redis：通过 AutoConfiguration.imports 注册 `YudaoRedisAutoConfiguration` 与 `YudaoCacheAutoConfiguration`。前者在 `RedissonAutoConfigurationV2` 之前执行，自定义 `RedisTemplate<String,Object>`，KEY 使用 String 序列化、VALUE 使用注入 JavaTimeModule 的 Jackson JSON 序列化；后者基于 `RedisCacheWriter` + `TimeoutRedisCacheManager` 实现带 TTL 的 `@Cacheable`，并开启事务感知以避免脏读。
依赖方向：业务 Mapper/Service 仅依赖本模块暴露的 `BaseMapperX`、`BaseDO`、`RedisTemplate`、`@Cache*` 注解，不直接感知底层 MyBatis Plus / Redisson 细节。
