本模块由三个独立的 Spring Boot Starter 组成，均通过 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册自动配置类，实现按需装配：
- `yudao-spring-boot-starter-monitor`：在 `tracer` 包下提供链路追踪能力，`YudaoTracerAutoConfiguration` 在存在 `io.opentelemetry.api.trace.Tracer` 时启用，注册 `BizTraceAspect`（AOP）和 `TraceFilter`（Servlet Filter），并通过 `TracerProperties` 暴露开关；同时提供 Metrics 自动配置。
- `yudao-spring-boot-starter-job`：在 `quartz` 包下集成 XXL-Job，`YudaoXxlJobAutoConfiguration` 读取 `XxlJobProperties` 并创建 `XxlJobSpringExecutor` Bean，同时开启 `@EnableScheduling` 支持原生定时任务；`YudaoAsyncAutoConfiguration` 提供异步线程池配置。
- `yudao-spring-boot-starter-protection`：集中提供四类横切防护能力，每个能力遵循统一分层：`config` 中定义 `Yudao*Configuration` 自动配置类，`core.annotation` 定义注解，`core.aop` 实现 AOP 切面，`core.keyresolver` 通过策略接口（如 `RateLimiterKeyResolver`、`IdempotentKeyResolver`）+ 多个 `impl/*` 实现解析维度（全局、用户、IP、节点、表达式），`redis` 子包封装 Redis 访问 DAO（如 `RateLimiterRedisDAO`、`IdempotentRedisDAO`、`ApiSignatureRedisDAO`）。
依赖方向单向向外：各 starter 仅依赖框架公共组件（common、redis、web），starter 之间互不依赖，通过 Spring Boot 自动配置机制组合使用。
