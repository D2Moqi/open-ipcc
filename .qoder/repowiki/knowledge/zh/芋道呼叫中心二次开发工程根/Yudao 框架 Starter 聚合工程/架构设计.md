本模块由两部分组成：yudao-framework 是 Maven 聚合 POM，按功能域将能力拆分为独立 starter（web/security/websocket、mybatis/redis、mq、monitor/protection/job、biz-tenant/biz-data-permission/biz-ip/excel/test/env/rpc），每个 starter 遵循 core + config 的双包结构并通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露自动装配；yudao-dependencies 是集中式 BOM，统一管理 Spring Boot/Cloud、MyBatis Plus、Redisson、XXL-Job、SkyWalking、Hutool、Fastjson2 等第三方依赖版本，并在 `<dependencyManagement>` 中声明所有 yudao-* 子模块的版本，使业务项目只需引入单个 starter 即可获得完整依赖树。starter 之间通过共享的 yudao-common 公共 POJO、异常体系与枚举解耦，业务特性 starter（如 tenant、data-permission）在运行时通过 AOP/Filter/Interceptor 横切到 web、mybatis、mq、job 等基础设施 starter 之上，形成“基础设施层 → 业务特性层”的分层组合模式。
