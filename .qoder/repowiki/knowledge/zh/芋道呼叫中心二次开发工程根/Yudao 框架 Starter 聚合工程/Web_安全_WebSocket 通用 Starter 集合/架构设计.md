本模块由三个独立的 Spring Boot Starter 组成，均通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册自动配置类：
- `yudao-spring-boot-starter-web`：以 `YudaoWebAutoConfiguration` 为核心，注册全局异常处理器、响应体处理器、CORS/请求体缓存/Demo Filter（按 `WebFilterOrderEnum` 排序）、`RestTemplate` 与负载均衡实例；并内聚 apilog、banner、desensitize、encrypt、jackson、swagger、xss 等子包，每个子包遵循 `config/*AutoConfiguration` + `core/*` 的目录约定，通过 `@EnableConfigurationProperties` 暴露可配项。
- `yudao-spring-boot-starter-security`：`YudaoSecurityAutoConfiguration` 在 `-1` 顺序优先于 Spring Security 默认配置，注入 `AuthenticationEntryPoint`、`AccessDeniedHandler`、`BCryptPasswordEncoder`、`TokenAuthenticationFilter`，并通过 `MethodInvokingFactoryBean` 将 `SecurityContextHolder` 策略切换为 `TransmittableThreadLocalSecurityContextHolderStrategy`；`YudaoWebSecurityConfigurerAdapter` 负责 URL 授权规则装配，`operatelog` 子包提供操作日志记录服务。
- `yudao-spring-boot-starter-websocket`：`YudaoWebSocketAutoConfiguration` 启用 `@EnableWebSocket`，注册握手拦截器、`JsonWebSocketMessageHandler`、`WebSocketSessionManager` 及授权定制器；通过内部 `@ConditionalOnProperty(prefix = "yudao.websocket", name = "sender-type")` 条件配置类，在 local/redis/rabbitmq/kafka/rocketmq 五种消息发送实现间动态切换，每种实现包含 Sender+Consumer 一对组件。
依赖方向：web starter 被 security 与 websocket starter 复用（如 `GlobalExceptionHandler`），security 与 websocket 之间无直接依赖，三者共同向上层业务应用提供开箱即用的基础设施。
