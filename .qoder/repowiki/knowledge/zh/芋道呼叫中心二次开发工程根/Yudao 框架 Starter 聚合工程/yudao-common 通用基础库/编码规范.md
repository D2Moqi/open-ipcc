- RPC 接口统一放在 `biz/<domain>/<module>/` 下，以 `<Name>CommonApi.java` 命名并配合同目录 `dto/` 下的请求/响应 DTO，通过 `@FeignClient(name = RpcConstants.<DOMAIN>_NAME)` 暴露。
- API 返回值统一使用 `CommonResult<T>`，并通过 `success(data)` / `error(ErrorCode, ...)` / `checkError()` 三件套处理成功与失败分支。
- 错误码集中管理于 `exception/enums/GlobalErrorCodeConstants`，新增错误时先在常量中登记，再通过 `ServiceException` 或 `CommonResult.error` 抛出。
- 工具类采用纯静态方法封装，无实例状态，按 `util/<domain>/` 子包划分（json、collection、date、string、object、http、io、servlet、spring、validation、monitor）。
- 自定义参数校验通过 `jakarta.validation.Constraint` 注解 + 同名 `XxxValidator` 实现的方式成对定义，如 `Mobile`/`MobileValidator`、`Telephone`/`TelephoneValidator`、`InEnum`/`InEnumValidator`。
- 所有第三方依赖在 `pom.xml` 中以 `provided` 作用域声明，避免将框架内部实现强加给使用者，仅保留编译期契约。
