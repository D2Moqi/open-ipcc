模块以 `cn.iocoder.yudao.framework.common` 为根包，按职责划分为五个子层：
- `pojo/`：定义全局统一返回体 `CommonResult<T>`、分页 `PageParam/PageResult`、排序字段等，作为所有 API 的响应契约。
- `exception/`：基于 `ErrorCode` + `GlobalErrorCodeConstants` + `ServiceErrorCodeRange` 构建错误码体系，并通过 `ServiceException`/`ServerException` 与 `CommonResult.checkError()` 打通异常与返回值的双向转换。
- `biz/`：按业务域（infra/system）组织 Feign CommonApi 接口及对应 DTO，如 `system/oauth2/OAuth2TokenCommonApi`、`system/dict/DictDataCommonApi`、`infra/logger/ApiAccessLogCommonApi`，通过 `@FeignClient(name = RpcConstants.SYSTEM_NAME)` 暴露跨服务 RPC 契约，实现“接口契约下沉到 common”的分层策略。
- `util/`：按领域划分的纯静态工具集（json/collection/date/string/object/http/io/servlet/spring/validation/monitor），全部无状态、可被任意上层模块直接调用。
- `validation/`：自定义 Jakarta Validation 注解（`Mobile`、`Telephone`、`InEnum`）及其 Validator 实现，供 Controller 入参校验复用。
- `enums/`：全局共享枚举（`CommonStatusEnum`、`UserTypeEnum`、`RpcConstants` 等）。
依赖方向单向向下：`biz` 依赖 `pojo`/`exception`/`enums`，`util` 不依赖业务包；所有 Spring/Web/Jackson 等第三方依赖在 `pom.xml` 中声明为 `provided`，确保本模块仅暴露契约而不引入运行时耦合。
