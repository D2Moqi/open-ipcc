本模块由三个相互独立的 Spring Boot Starter 组成，均遵循 `config` + `core` + `package-info.java` 的分层约定：
- `yudao-spring-boot-starter-test`：通过 `BaseDbUnitTest` / `BaseRedisUnitTest` / `BaseDbAndRedisUnitTest` / `BaseMockitoUnitTest` 四个继承型基类封装常用测试场景；`BaseDbAndRedisUnitTest` 使用 `@SpringBootTest` + `@Import` 显式引入数据源、MyBatis-Plus、Druid、Redis、Redisson 等配置类，并配合 `application-unit-test` profile 与 `/sql/clean.sql` 在测试后清理 DB；`config/RedisTestConfiguration` 和 `SqlInitializationTestConfiguration` 分别启动内存 Redis 与执行 SQL 初始化。
- `yudao-spring-boot-starter-env`：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `YudaoEnvWebAutoConfiguration` 与 `YudaoEnvRpcAutoConfiguration` 两个条件化自动配置；前者在 Servlet Web 环境下注册 `EnvWebFilter`，后者注入自定义 `LoadBalancerClientFactory` 与 `EnvRequestInterceptor`，实现按环境标签路由 Feign 请求的能力；配置属性集中在 `EnvProperties`，并通过 `@EnableConfigurationProperties` 暴露。
- `yudao-spring-boot-starter-rpc`：仅声明依赖 `spring-cloud-starter-openfeign`、`spring-cloud-starter-loadbalancer`、`feign-okhttp`，作为 OpenFeign 客户端的轻量 Starter，当前 `config` 与 `core` 包下为占位 `package-info.java`，实际能力由上层业务或 env starter 组合使用。
依赖方向：test starter 依赖 mybatis/redis starter 以复用其自动配置；env starter 依赖 common、web、loadbalancer、feign-core、nacos-discovery；rpc starter 仅依赖 common 与 spring-cloud openfeign/loadbalancer，三者彼此无直接耦合。
