- 每个能力以独立 Maven module 形式提供，命名遵循 `yudao-spring-boot-starter-*`，并按功能域分组聚合于父 POM 的 modules 列表中
- 每个 starter 内部采用 `core`（核心实现）+ `config`（Spring 配置类）+ `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 的标准自动装配结构
- 跨 starter 共享的 POJO、异常、枚举、工具类统一收敛到 yudao-common，其他 starter 仅通过该模块进行类型通信，避免直接耦合
- 所有第三方依赖版本集中在 yudao-dependencies 的 properties 与 dependencyManagement 中声明，starter 自身不指定版本号
- starter 之间通过 Spring 自动装配而非硬编码依赖组合，业务特性 starter（tenant/data-permission/ip/excel）以可插拔方式叠加到基础设施 starter 之上
