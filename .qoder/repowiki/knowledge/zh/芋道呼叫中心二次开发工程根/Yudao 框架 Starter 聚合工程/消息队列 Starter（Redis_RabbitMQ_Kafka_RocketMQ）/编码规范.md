- 每个 MQ 实现独立一个 `config/*AutoConfiguration` 类，并通过 `META-INF/spring/...AutoConfiguration.imports` 集中注册，实现按需自动装配。
- 对可选依赖的 MQ 实现使用 `@ConditionalOnClass` 或 Maven `<optional>true</optional>` 声明，确保未引入对应依赖时不影响 starter 启动。
- 消息模型采用抽象基类 + 子类扩展的模式：`AbstractRedisMessage` 提供通用 headers，再派生 `AbstractRedisChannelMessage` / `AbstractRedisStreamMessage` 承载各模式特有字段。
- 发送流程统一经 `RedisMQTemplate`，并通过 `RedisMessageInterceptor` 列表在 `sendMessageBefore/sendMessageAfter` 中执行正序/倒序拦截器链。
- 消费者监听容器通过 `@ConditionalOnBean(AbstractRedis*Listener.class)` 条件注册，只有存在自定义 Listener 时才创建对应的 RedisMessageListenerContainer 或 StreamMessageListenerContainer。
