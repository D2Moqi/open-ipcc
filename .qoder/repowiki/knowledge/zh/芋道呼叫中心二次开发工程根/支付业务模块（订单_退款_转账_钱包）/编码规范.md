- 每个业务域（order/refund/transfer/wallet/app/channel/notify/demo）均遵循 Controller → Service → DAL（DO + Mapper）→ Convert 的分层结构，VO/DTO/BO/DO 严格分离。
- RPC 接口以 `@FeignClient(name = ApiConstants.NAME)` 声明在 api 模块中，并以 `PREFIX` 常量拼接路径，服务端通过同名 `ApiImpl` 实现。
- 支付渠道通过 `PayChannelEnum` 编码区分，并在 `PayClientFactoryImpl` 构造函数中以 channelCode → Client Class 的映射集中注册，新增渠道无需修改工厂逻辑。
- 所有枚举实现 `ArrayValuable` 并提供 `getByCode` 静态查找方法，同时提供 `isAlipay`/`isWeixin` 等前缀判断辅助方法。
- 错误码集中定义在 `ErrorCodeConstants`，业务异常通过 `ServiceExceptionUtil.exception(错误码, 参数...)` 抛出。
- 对象转换统一使用 MapStruct 的 `XxxConvert.INSTANCE.convert(...)` 风格，按领域划分 convert 子包。
