所有操作需在 `sql/tools/` 目录下执行。快速启动测试库：`docker compose up -d <db>`；销毁重建需先 `docker compose down <db>` 再 `docker volume rm ruoyi-vue-pro_<db>`。MySQL 转其他方言：`pip install simple-ddl-parser` 后运行 `python3 convertor.py <postgres|oracle|sqlserver|dm8|kingbase|opengauss|highgo> ../mysql/ruoyi-vue-pro.sql > <target>/ruoyi-vue-pro.sql`。DM8/Kingbase/OpenGauss/SQL Server 启动后需手动执行 `docker compose exec <db> bash /tmp/create_schema.sh` 或对应客户端命令导入脚本。
