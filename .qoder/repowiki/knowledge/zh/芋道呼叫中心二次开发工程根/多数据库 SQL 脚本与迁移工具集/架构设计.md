模块按目标数据库分目录组织：每个数据库子目录（mysql/postgresql/oracle/sqlserver/dm/highgo/kingbase/opengauss）均包含两份脚本——`ruoyi-vue-pro.sql`（业务表结构+数据）和 `quartz.sql`（Quartz 调度表），保持各方言版本并行维护。

核心转换逻辑集中在 `tools/convertor.py`：定义抽象基类 `Convertor`，通过 `simple-ddl-parser` 解析 MySQL 源 DDL，再由 `PostgreSQLConvertor`、`OracleConvertor`、`SQLServerConvertor`、`DM8Convertor`、`KingbaseConvertor`（继承自 PostgreSQLConvertor）等子类实现 `translate_type`、`gen_create`、`gen_index`、`gen_comment`、`gen_pk`、`gen_uk`、`gen_insert`、`gen_dual` 等方法，将 MySQL 建表语句翻译为目标方言 SQL；`load_and_clean` 负责预处理字符集、索引前缀长度、ENGINE/COMMENT 等 MySQL 特有语法。

`tools/docker-compose.yaml` 提供 MySQL、Oracle、PostgreSQL、SQL Server、DM8、Kingbase、OpenGauss、HighGo 等测试数据库的容器编排，部分数据库（SQL Server、DM8、Kingbase、OpenGauss）因镜像不支持自动初始化脚本，需手动执行 `tools/{db}/create_schema.sh` 或 `docker compose exec ...` 命令导入 `/tmp/schema.sql`。

依赖方向单向：`convertor.py` → `simple-ddl-parser`；各数据库目录仅存放静态 SQL，无相互引用；`dm/flowable-patch` 是独立的 Java 补丁包，用于在达梦环境下扩展 Liquibase Flowable 支持（`DmDatabase`、`BooleanType`、`AbstractEngineConfiguration` 覆盖）。
