- 所有文档与原型页面以 HTML 单页形式存放于 `pages/<分类>/<页面>.html`，由 `app.js` 中的 `menuData` 通过 url 字段统一路由加载到 iframe。
- 图片资源按主题语义分目录存放于 `assets/images/<主题>/`，文件名采用 `u<序号>.svg|png|gif` 或中文命名（如示例、判定_*.svg）。
- 菜单项结构统一包含 `id`（唯一标识）、`name`（显示名）、`url`（相对路径）三字段，新增页面只需在 `menuData` 中追加条目即可被导航发现。
- UI 交互通过 Vue 3 响应式数据驱动（activeTabIndex、activeMenuId、iframeSrc、isCollapsed），事件处理函数集中定义在 methods 中并附带详细 JSDoc 注释。
- Element-Plus 组件通过本地脚本引入而非 npm 依赖，并在 `index.html` 中以固定顺序加载 CSS、Vue、Element-Plus、中文包、icons 与主应用脚本。
