模块采用 Maven 多模块结构：`yudao-module-report-api` 仅暴露 API 常量（ErrorCodeConstants）供其他模块引用；`yudao-module-report-server` 为可独立部署的 Spring Boot 服务，入口为 `ReportServerApplication`。

服务内部按经典分层组织：`controller/admin/goview` 暴露管理端 REST 接口（如 `/report/go-view/project`），通过 `@PreAuthorize("@ss.hasPermission(...)")` 进行权限控制；`service/goview` 定义业务接口与实现；`dal/dataobject` 使用 MyBatis-Plus 的 `BaseDO` + `@TableName` 映射到 `report_go_view_project` 表；`dal/mysql` 提供 Mapper；`convert/goview` 负责 VO 与 DO 转换。

第三方报表集成集中在 `framework/jmreport`：`JmReportConfiguration` 通过 `@ComponentScan("org.jeecg.modules.jmreport")` 扫描积木报表包，并注册自定义的 `JmReportTokenServiceImpl`（对接 OAuth2 与权限系统）及 `JmOnlDragExternalServiceImpl`（扩展拖拽能力）。同时依赖 `yudao-spring-boot-starter-security`、`yudao-spring-boot-starter-mybatis`、`yudao-spring-boot-starter-rpc`、Nacos 注册/配置中心以及 `jimureport-spring-boot3-starter` / `jimubi-spring-boot3-starter`。

依赖方向严格单向：server → api → common；测试位于 `src/test`，使用 `application-unit-test.yaml` 与 SQL 脚本初始化数据库。
