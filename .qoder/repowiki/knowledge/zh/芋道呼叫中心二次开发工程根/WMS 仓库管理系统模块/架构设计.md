模块采用 Maven 多模块拆分：`yudao-module-wms-api` 仅暴露枚举常量（如 `ApiConstants`、`ErrorCodeConstants`、`DictTypeConstants` 及各业务域枚举），供其他模块通过 RPC 调用；`yudao-module-wms-server` 为可独立部署的 Spring Boot 应用（入口 `WmsServerApplication`），内部按领域子包划分 controller/dal/service，并通过 `framework.rpc.config.RpcConfiguration`、`framework.security.config.SecurityConfiguration`、`framework.web.config.WmsWebConfiguration` 完成 RPC、安全与 Web 配置。

分层结构清晰：controller（admin 下按 inventory/md/order 等业务域组织 VO）→ service（接口+Impl，order 域进一步拆分为 receipt/movement/shipment/check 四个子域，每个子域含 order/detail 两个 Service）→ dal（dataobject 对应 DO，mysql 下 MyBatis Mapper + resources/mapper/*.xml）。数据访问统一使用 MyBatis，测试用例位于 `src/test` 并配套 `sql/create_tables.sql` 与 `sql/clean.sql` 初始化脚本。

依赖方向单向：controller → service → mapper；order 类 Service 通过 `WmsInventoryService.changeInventory` 触发库存变更，形成跨领域协作边界。
