模块采用 Maven 多模块结构，由根 pom.xml 聚合两个子模块：
- yudao-module-mes-api：纯 Java 共享包，仅依赖 yudao-common 与可选的 spring-boot-starter-validation，集中存放各业务域的枚举常量（cal/dv/md/pro/qc/tm/wm 等子包）、全局错误码 ErrorCodeConstants、字典/业务类型常量以及 RPC 服务名 ApiConstants（NAME=mes-server, PREFIX=/mes），作为跨模块调用的契约层。
- yudao-module-mes-server：可独立部署的微服务应用，入口为 MesServerApplication.java，通过 Spring Boot + Nacos（注册中心+配置中心）启动；依赖 yudao-spring-boot-starter-security、mybatis、redis、rpc、tenant、excel、monitor 等 starter 装配通用能力。

代码按经典分层组织：controller/admin 下以 cal/dv/md/pro/qc/tm/wm/home 等业务域划分 REST 控制器；service 层按相同域拆分接口与 Impl；dal 层包含 dataobject（DO）、mysql Mapper 及 Redis DAO；resources/mapper 放置 MyBatis XML；framework 下封装本模块的 RpcConfiguration 与 SecurityConfiguration。

依赖方向严格单向：server → api → common；各业务域内部遵循 controller→service→(mapper/redis)→DB 的调用链，并通过 ErrorCodeConstants 统一返回业务异常码（1_040_xxx_xxx 段）。测试位于 src/test，使用 application-unit-test.yaml 与 SQL 脚本初始化环境。
