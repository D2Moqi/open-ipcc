本模块是 yudao-cloud 的单体部署形态（jar 包），自身不含业务逻辑，仅作为 Spring Boot 启动容器：
- 入口类 YudaoServerApplication 使用 @SpringBootApplication 并扫描 ${yudao.info.base-package}.server、${yudao.info.base-package}.module 以及 cn.ipcc.sipproxy 三个包，将各 module 的 Controller/Service 等组件纳入同一 JVM。
- pom.xml 中显式声明已启用的模块依赖（yudao-module-system-server、yudao-module-infra-server、yudao-module-cc-server），其余模块（bpm/mp/mall/crm/erp/wms/im/ai/iot 等）以注释形式保留，便于按需开启编译，体现“可插拔模块”聚合模式。
- 通过排除 spring-cloud-starter-openfeign 并在 application.yaml 中关闭 Nacos discovery/config，使该 jar 以单体模式运行；同时启用 xxl-job、Flowable、MyBatis-Plus、Redis、Kafka/RocketMQ、AI（OpenAI/Anthropic/Gemini 等）等通用能力配置。
- DefaultController 为每个被禁用模块提供 /admin-api/{module}/** 的兜底接口，统一返回 NOT_IMPLEMENTED 错误码与启用指引，避免未启用模块直接 404。
- resources 下按环境划分 application-{dev|local}.yaml，配合 logback-spring.xml 完成日志输出。
