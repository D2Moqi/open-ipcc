- 每个业务域在 server 层统一按 controller/admin、service、dal/dataobject、dal/mysql、convert 五个子包组织，VO/DO/DTO 分离并通过 MapStruct Convert 实例进行转换。
- 对外 RPC 能力以 api 模块中的 @FeignClient 接口定义，并在 server 模块的 api/impl 包下提供同名 *Impl 实现，接口路径前缀统一来自 ApiConstants。
- 管理端 Controller 方法统一返回 CommonResult<T>，并使用 @PreAuthorize("@ss.hasPermission('infra:xxx:action')") 进行细粒度权限控制。
- 枚举集中放在 enums/ 目录下按领域分包（config、codegen、logger 等），错误码与字典常量分别通过 ErrorCodeConstants、DictTypeConstants、ApiConstants 集中维护。
- 代码生成模板以 Velocity 形式存放在 resources/codegen/{java,sql,vue,vue3,vue3_vben*} 目录，通过 CodegenFrontTypeEnum / CodegenTemplateTypeEnum 选择不同前端/后端模板组合。
- 异步与跨进程通信通过 job/、mq/、websocket/ 三个顶层包隔离：job 存放 XXL-Job 任务类，mq 按 producer/consumer/message 分层，websocket 通过 WebSocketSenderApi 抽象发送类型（local/redis/mq）。
