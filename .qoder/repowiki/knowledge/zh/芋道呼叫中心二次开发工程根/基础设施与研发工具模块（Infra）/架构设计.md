模块采用 Maven 多模块结构，根 pom.xml 聚合 yudao-module-infra-api（仅含 Feign API 接口、DTO 与枚举常量）和 yudao-module-infra-server（可独立启动的 Spring Boot 服务）。server 层按功能域划分为 config、file、db、logger、codegen、redis、demo 等子包，每域遵循 controller → service → dal(dataobject + mysql mapper) → convert 的分层约定；controller 位于 admin/ 下暴露 REST 接口，app/ 下暴露应用侧接口，api/ 下实现 FeignClient 接口的服务端实现供其他微服务通过 RPC 调用。框架扩展集中在 framework/ 子包（codegen/file/monitor/rpc/security），通过 starter 方式注入到业务中。资源目录 resources/codegen/ 内置 Velocity 模板（java/sql/vue/vue3/vue3_vben* 等多前端风格），由 CodegenService 驱动代码生成。启动类 InfraServerApplication 配合 application.yaml 加载本地与 Nacos 配置，端口默认 48082，并通过 xxl-job、Kafka/RocketMQ、Nacos 注册/配置中心集成分布式能力。
