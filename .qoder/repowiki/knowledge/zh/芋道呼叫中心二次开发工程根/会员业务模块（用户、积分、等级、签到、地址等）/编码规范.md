- 每个业务域（user/address/config/level/point/signin/tag/group）均遵循 controller → service → convert → dal 的分层目录划分，并在 api 子模块中提供对应的 Feign API 接口与 DTO。
- RPC 接口统一使用 @FeignClient(name = ApiConstants.NAME) 并基于 ApiConstants.PREFIX 拼接路径，通过 CommonResult<T> 包装返回值。
- VO/DTO/DO 之间的转换统一放在 convert/<domain>/<Domain>Convert.java 中，以静态 INSTANCE 或 MapStruct 组件形式调用。
- Controller 使用 @Tag/@Operation/@Parameter 注解标注 Swagger 文档，并以 /member/... 作为 URL 前缀区分 admin 与 app 两套控制器。
- 事务性写操作在 ServiceImpl 上使用 @Transactional(rollbackFor = Exception.class)，并在 afterCommit 回调中通过 MQ Producer 发送异步事件。
- 对外部系统（短信、社交登录、日志）的调用通过 Feign 接口注入（SmsCodeApi、SocialClientApi、LoginLogApi），而非直接依赖其实现。
