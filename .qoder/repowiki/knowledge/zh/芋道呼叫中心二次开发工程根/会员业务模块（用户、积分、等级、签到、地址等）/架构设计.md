模块采用 Maven 多模块结构，由根 pom.xml 聚合 yudao-module-member-api 与 yudao-module-member-server 两个子模块：
- api 子模块仅包含纯 Java 契约：按领域（user/address/config/level/point/signin/tag/group/message）划分的 Feign API 接口、DTO 以及常量（ApiConstants、ErrorCodeConstants、DictTypeConstants、各 BizTypeEnum），作为跨服务 RPC 边界。
- server 子模块是独立可部署的 Spring Boot 应用（MemberServerApplication），内部按典型分层组织：controller/admin 与 controller/app 分别面向后台管理与移动端；service 层以接口+实现类封装业务；dal 层通过 dataobject（DO）、mysql（MyBatis Mapper）访问数据库；convert 层使用 MapStruct 在各层 VO/DTO/DO 之间转换；mq.producer 通过消息发送跨进程事件（如 MemberUserProducer）；framework.rpc 中 RpcConfiguration 集中 @EnableFeignClients 引入 system 模块的 SmsCodeApi/SocialClientApi 等外部依赖。
- 安全与 RPC 配置分离在 framework.security.config.SecurityConfiguration 与 framework.rpc.config.RpcConfiguration 中，避免污染业务代码。
- 依赖方向单向：controller → service → (convert) → dal/mq，并通过 Feign 调用 system 模块，不反向依赖。
