模块采用 Maven 多模块拆分：`yudao-module-bpm-api` 仅包含对外 RPC 接口（`api/task/BpmProcessInstanceApi`）、事件 DTO、枚举常量（`enums/definition`、`enums/task`、`enums/message`）和 `ApiConstants`；`yudao-module-bpm-server` 是完整可部署的 Spring Boot 应用，按分层组织：`controller/admin` 暴露管理端 HTTP 接口（分类、表单、模型、流程定义、OA 请假、实例与任务），`service` 实现业务编排，`dal` 通过 MyBatis Mapper + DO 对象持久化，`convert` 使用 MapStruct 在 VO/DTO/DO 间转换，`framework/flowable` 深度定制 Flowable：`config/BpmFlowableConfiguration` 注册 `EngineConfigurationConfigurer`、自定义 `ActivityBehaviorFactory`、异步线程池及监听器；`core/candidate` 以策略模式实现多种审批人分配方式（部门、岗位、角色、表达式、发起人等），由 `BpmTaskCandidateInvoker` 统一调度；`core/listener` 提供流程实例/任务生命周期监听；`core/behavior` 扩展并行/串行多人会签等行为；`core/util` 封装 BPMN 模型与变量工具。依赖方向严格单向：server → api → common，跨模块通过 Feign 调用。
