- 每个业务域在 `src/views/{domain}/`、`src/api/{domain}/`、`src/components/` 下各自建立独立目录，保持视图、API 与组件的物理隔离。
- 页面统一采用「列表 + 搜索 + 弹窗表单」三段式结构，复用 `src/components/Table`、`src/components/Form`、`src/components/Dialog` 等通用组件。
- 所有 HTTP 请求集中在 `src/api/{domain}/*.ts` 中定义并返回 Promise，页面侧只负责调用与错误展示，不直接操作 axios。
- 权限控制通过 `v-permission` 指令与 `src/utils/permission.ts` 的权限码判断实现，按钮级可见性由后端菜单/权限码驱动。
- 字典数据统一通过 `src/utils/dict.ts` 与 `DictTag` 组件渲染，避免在业务页面硬编码枚举值。
- 多语言文案集中放在 `src/locales/zh-CN.ts` 与 `en.ts`，页面通过 `useI18n()` 获取翻译键。
