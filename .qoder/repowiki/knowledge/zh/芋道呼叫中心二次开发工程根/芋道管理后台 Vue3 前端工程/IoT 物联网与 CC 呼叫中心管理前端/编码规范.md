- 每个业务资源目录下均保持 views 与 api 同构布局，api 文件以 `XxxApi` 对象形式集中导出 CRUD 方法，并使用 TypeScript interface 声明 VO/ReqVO 类型。
- 列表页统一采用 ContentWrap 包裹搜索表单与表格，使用 Pagination 组件配合 queryParams 的 pageNo/pageSize 进行分页，删除操作通过 message.delConfirm() 二次确认。
- 按钮级权限通过 v-hasPermi 指令绑定后端权限字符串（如 `iot:device:create`、`cc:area-code:delete`），而非前端硬编码判断。
- 字典值展示统一使用 dict-tag 或 getDictLabel(DICT_TYPE.XXX, value) 进行翻译，下拉选择使用 getIntDictOptions(DICT_TYPE.XXX) 生成选项。
- 复杂表单拆分为多个 Section/Config 子组件，通过 v-model 双向绑定与 ref 暴露 validateAllXxx 方法进行分步校验后统一提交。
- IoT 物模型的数据定义按数据类型（Number/Enum/Array/Struct）拆分为独立的 ThingModel*DataSpecs 组件，并通过 index.ts 统一导出。
