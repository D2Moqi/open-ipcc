- 每个视图文件顶部通过 `defineOptions({ name: 'xxx' })` 显式声明组件名称，便于调试与路由标识。
- 登录态在多个表单间共享，通过 `useLogin.ts` 中模块级 `ref` + `LoginStateEnum` 枚举实现跨组件状态同步。
- 表单组件统一在 `Login/components/index.ts` 中集中 re-export，再由 `Login.vue` 一次性引入，避免散落的 import 路径。
- 错误页面采用薄壳模式：403/404/500 仅传递 `type` 参数并绑定 `push('/')` 回调，将 UI 细节委托给通用 `Error` 组件。
- 首页数据加载使用 `Promise.all` 并行获取多组数据后统一关闭 loading，并在模板中使用 `el-skeleton` 包裹对应区域以提供骨架屏体验。
