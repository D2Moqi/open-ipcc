模块按功能划分为三个并列的 views 子目录：
- Login：以 `Login.vue` 为入口，通过左右分栏布局承载左侧品牌展示与右侧表单区；表单逻辑下沉到 `components/` 下的独立表单组件（LoginForm/MobileForm/QrCodeForm/RegisterForm/SSOLogin/ForgetPasswordForm），并通过 `components/index.ts` 统一导出，由 `useLogin.ts` 中的 `useLoginState()` 暴露共享的 `LoginStateEnum` 状态机驱动各表单切换，`useFormValid` 封装 Element Plus 表单校验。
- Home：`Index.vue` / `Index2.vue` 作为工作台页面，使用 Element Plus 栅格 + Card 组织统计卡片、项目列表、快捷入口与公告，图表数据集中放在 `echarts-data.ts`，类型定义放在 `types.ts`，通过 `Echart` 组件渲染 ECharts 配置。
- Error：`403.vue`、`404.vue`、`500.vue` 均为薄包装页，仅负责传入 `type` 并监听 `error-click` 事件跳转回首页，具体 UI 由全局 `Error` 组件复用。
依赖方向单向向外：视图层调用 `@/store`、`@/hooks/web`、`@/layout/components` 等公共能力，不反向依赖业务模块。
