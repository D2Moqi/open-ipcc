- 每个业务域目录遵循「index.vue 列表 + Form.vue 表单 + detail/ 详情」三段式结构，详情页拆分为 Header、Info、ProductList 等子组件。
- 列表页统一使用 `ContentWrap` 包裹搜索表单与表格，搜索参数集中维护在 `queryParams` reactive 对象中，并通过 `handleQuery/resetQuery` 标准化查询流程。
- 所有后端请求集中在 `src/api/crm/<domain>/index.ts` 中以函数或对象方法形式暴露，并配套定义 TypeScript VO 接口，视图侧通过 `import * as XxxApi` 方式引入。
- 按钮级权限通过 `v-hasPermi="['crm:<domain>:<action>']"` 指令控制，如 `crm:customer:create`、`crm:customer:update`、`crm:customer:delete`。
- 枚举/字典字段在模板中使用 `dict-tag` 配合 `DICT_TYPE.*` 常量进行展示，下拉选择则通过 `getIntDictOptions(DICT_TYPE.*)` 生成选项。
- 详情页通过 `BizTypeEnum.CRM_<DOMAIN>` 将自身 bizId/bizType 传递给通用组件（FollowUpList、ContactList、ContractList、PermissionList、OperateLogV2），实现跨域复用。
- 统计类页面采用「父容器 el-tabs + 子组件 ref.loadData()」模式，父级统一管理 queryParams，切换 tab 时调用当前子组件的 `loadData` 方法刷新图表。
- 待办中心 `backlog/index.vue` 使用左侧菜单数组 + `v-if` 条件渲染子组件的方式聚合多域待办项，并通过 badge 显示未读计数。
