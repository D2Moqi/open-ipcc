- 每个资源目录采用 `index.vue`（列表+搜索+分页+操作按钮）+ `XxxForm.vue`（新增/编辑/详情复用）+ 可选 `components/` 子组件的结构组织。
- API 文件以命名对象（如 `ProductApi`、`FinancePaymentApi`）集中暴露增删改查、分页、导出等方法，并在同一文件中声明对应 VO 接口。
- 列表页统一使用 `queryParams`（含 pageNo/pageSize）驱动分页，通过 `getList/handleQuery/resetQuery` 三函数模式管理查询状态。
- 表格列中价格字段统一使用 `erpPriceTableColumnFormatter`、数量字段使用 `erpCountTableColumnFormatter` 格式化，状态字段使用 `dict-tag` 配合 `DICT_TYPE.ERP_AUDIT_STATUS` 展示。
- 所有写操作（删除、审批/反审批、导出）均包裹 `message.delConfirm/exportConfirm/confirm` 二次确认后再调用 API。
- 按钮级权限通过 `v-hasPermi` 指令绑定 `erp:<resource>:<action>` 形式的权限码，与后端资源命名保持一致。
