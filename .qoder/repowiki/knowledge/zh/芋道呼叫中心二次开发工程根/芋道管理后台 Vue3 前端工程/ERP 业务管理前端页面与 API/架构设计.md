模块按业务子域划分目录：`views/erp/{product,purchase,sale,stock,finance,home}` 各子域下再按资源（如 `order/in/out/return/supplier`）组织，每个资源目录遵循统一的三件套结构——`index.vue` 列表页、`XxxForm.vue` 表单弹窗、可选 `components/` 存放行级明细表单或关联选择器；对应的 `api/erp/{domain}/resource/index.ts` 通过命名对象（如 `ProductApi`、`PurchaseOrderApi`）封装 RESTful 方法并定义 VO 接口，统一经由 `@/config/axios` 发起请求。依赖方向单向：视图层 → 本模块 api 层 → 全局 axios 实例，跨域数据（如供应商、用户、产品）通过引入其他模块的 Api 获取。首页 `home/index.vue` 作为聚合看板，组合 `statistics/purchase` 与 `statistics/sale` 两个统计 API 渲染 SummaryCard 与 TimeSummaryChart 组件。
