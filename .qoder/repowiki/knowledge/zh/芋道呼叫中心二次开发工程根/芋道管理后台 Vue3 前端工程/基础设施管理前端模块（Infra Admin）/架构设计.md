模块按后端业务域一一对应划分目录，`src/views/infra/<domain>/index.vue` 作为列表页入口，配合同目录的 `*Form.vue`、`*Detail.vue` 以及子组件构成完整 CRUD 视图；对应的 HTTP 接口统一集中在 `src/api/infra/<domain>/index.ts`，通过 `@/config/axios` 发起请求并导出类型定义与函数。依赖方向单向：View → api → axios，各 domain 之间无相互调用，仅 `codegen/index.vue` 在运行时按需引入 `dataSourceConfig` 的 API 以联动数据源选择。部分功能为纯展示型单页（如 `druid`、`redis`、`server`、`skywalking`、`swagger`、`webSocket`），直接嵌入第三方 iframe 或只读面板。权限控制通过全局指令 `v-hasPermi` 与 `checkPermi` 工具在按钮级裁剪操作入口。
