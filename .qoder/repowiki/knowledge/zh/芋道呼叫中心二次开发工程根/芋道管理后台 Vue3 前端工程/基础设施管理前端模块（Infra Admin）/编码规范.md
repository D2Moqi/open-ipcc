- 每个业务域在 `views/infra` 和 `api/infra` 下保持同名子目录，列表页统一命名为 `index.vue`，表单/详情以 `XxxForm.vue`、`XxxDetail.vue` 命名并独立成文件。
- API 层文件统一先声明 VO/ReqVO 类型，再按增删改查顺序导出函数，所有请求均通过 `request.get/post/put/delete/download/upload` 调用，URL 前缀固定为 `/infra/...`。
- 列表页采用标准模板：顶部 `ContentWrap` 包裹搜索表单，中部 `el-table` 绑定分页 `Pagination`，底部通过 `ref` 打开弹窗形式的 Form/Detail，并在 `onMounted` 中调用 `getList`。
- 查询参数集中定义为 `reactive({ pageNo, pageSize, ... })`，搜索重置时调用 `queryFormRef.resetFields()` 后重新触发查询。
- 导出与删除等危险操作统一通过 `message.confirm` / `message.exportConfirm` / `message.delConfirm` 二次确认后执行，并在 try/finally 中维护 loading 状态。
- 所有可操作按钮使用 `v-hasPermi="['infra:<domain>:<action>']"` 进行权限裁剪，菜单级权限通过 `defineOptions({ name: 'InfraXxx' })` 与路由注册保持一致。
