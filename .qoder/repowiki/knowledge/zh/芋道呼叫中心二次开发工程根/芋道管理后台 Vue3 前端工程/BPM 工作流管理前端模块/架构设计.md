模块按业务域划分为 views/bpm 与 api/bpm 两个对称目录：每个子领域（category、model、form、processInstance、task、processListener、processExpression、simple、oa/leave、group）在 views 下提供列表页与表单/详情页，在 api 下提供同名 index.ts 封装 HTTP 调用，统一通过 `@/config/axios` 发起请求。
- 入口与编排：`views/bpm/model/form/index.vue` 作为流程建模向导，通过步骤条串联 BasicInfo → FormDesign → ProcessDesign → ExtraSettings 四个子组件，并使用 provide/inject 共享 modelData/processData；`views/bpm/processInstance/detail/index.vue` 作为审批详情主容器，用 el-tabs 组合 ProcessInstanceBpmnViewer/SimpleViewer、ProcessInstanceTimeline、ProcessInstanceTaskList、ProcessInstanceCommentList、ProcessInstanceOperationButton 等子组件。
- 视图层采用 Composition API `<script setup>` + ref 状态管理，通过 `useMessage`、`useTagsViewStore` 等全局 hooks 处理消息与标签页；表单渲染使用 form-create（`@form-create/element-ui`），流程图渲染依赖 SimpleProcessDesignerV2 与 BPMN 查看器。
- API 层以枚举集中定义状态（如 `TaskStatusEnum`），函数命名遵循动词+资源风格（getTaskTodoPage、approveTask、createProcessInstance），并通过 TypeScript 类型导出（ProcessInstanceVO、ApprovalNodeInfo 等）供视图消费。
- 依赖方向单向：views → api → @/config/axios；跨领域复用通过共享常量（`@/utils/constants` 中的 BpmModelType/BpmModelFormType）与组件（SimpleProcessDesignerV2）完成。
