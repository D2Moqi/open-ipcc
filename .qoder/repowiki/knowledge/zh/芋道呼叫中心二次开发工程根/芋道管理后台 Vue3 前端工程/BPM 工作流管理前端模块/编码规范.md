- API 文件按业务域拆分到 `src/api/bpm/<domain>/index.ts`，每个文件集中导出该域的所有接口函数与类型，并通过 `request.get/post/put/delete` 统一封装。
- 视图组件统一使用 `<script setup lang="ts">` 语法，配合 `ref`/`reactive` 管理本地状态，并通过 `defineOptions({ name: '...' })` 显式声明组件名。
- 流程相关状态使用集中枚举表达，如 `TaskStatusEnum`、`BpmModelType`、`BpmModelFormType`，避免在视图中硬编码数字状态码。
- 复杂页面采用“主容器 + 多子组件”组合模式：主 index.vue 负责数据加载与布局，具体功能（流程图、时间线、评论、操作按钮）拆分为独立 Vue 组件并通过 props/ref 通信。
- 表单设计类页面采用分步向导结构，通过 steps 数组驱动 currentStep 切换，并在父组件中通过 ref 调用子组件的 validate() 方法实现分步校验。
- 流程模型数据通过 provide/inject 在父子组件树间共享（如 provide('modelData', formData)、provide('processData', processData)），减少多层 props 透传。
