- 每个业务域在 views/system 与 api/system 下保持同名目录，列表页 index.vue 通过 import * as XxxApi from '@/api/system/<domain>' 调用对应 API。
- 列表页统一采用「搜索表单 + el-table + Pagination」三段式布局，使用 reactive 定义 queryParams（含 pageNo/pageSize），并通过 v-loading 控制表格加载态。
- 新增/修改/导入/分配等弹窗以独立 .vue 组件形式存在，通过父组件 ref 调用 open(type, id) 方法打开，并在提交成功后 emit('success') 触发 getList() 刷新。
- 所有可操作按钮均使用 `v-hasPermi="['system:<domain>:<action>']"` 指令进行权限控制，配合 `checkPermi([...])` 动态禁用行内操作（如状态切换开关）。
- 字典值展示统一通过 `dict-tag` 或 `getIntDictOptions(DICT_TYPE.XXX)` 获取选项，避免硬编码枚举文本。
- 导出功能遵循「二次确认 → 设置 loading → 调用 exportXxx(params) → download.excel(data, name)」的统一流程，删除类操作统一调用 message.delConfirm() 二次确认。
