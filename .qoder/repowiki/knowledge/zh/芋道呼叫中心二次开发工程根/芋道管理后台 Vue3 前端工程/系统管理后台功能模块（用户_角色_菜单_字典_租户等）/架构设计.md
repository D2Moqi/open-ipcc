模块按后端资源域划分为 views/system/<domain>/ 与 api/system/<domain>/ 一一对应的目录结构，每个 domain 包含一个 index.vue 列表页及若干表单/详情子组件（如 user/index.vue + UserForm.vue/UserImportForm.vue/UserAssignRoleForm.vue）。API 层集中在 src/api/system/ 下，每个 domain 的 index.ts 通过统一封装的 `@/config/axios` 发起 HTTP 请求并导出类型化接口，视图层仅依赖这些 API 而不直接调用 axios。跨领域复用组件（如 DeptTreeSelect、UserSelect、SmsTemplateSelect、NotifyTemplateSelect 等）放在各自 components 子目录供其他页面引用。权限控制通过全局指令 `v-hasPermi` 与工具函数 `checkPermi` 在按钮/菜单粒度进行渲染级拦截。整体依赖方向：views → @/api/system/* → @/config/axios → 后端 REST 接口；视图之间不直接互相调用，仅通过 ref + emit('success') 触发父列表刷新。
