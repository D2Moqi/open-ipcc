工程以 `src/main.ts` 为入口，依次初始化 Pinia、Vue Router、Element Plus、i18n、UnoCSS、自定义指令与全局插件；`src/router/index.ts` 集中注册静态路由并通过 `src/permission.ts` 在路由守卫中按后端菜单动态加载权限路由，从而把各业务子模块（system、bpm、crm、erp、im、iot、ai、mall、member、pay、mp、mes、cc、report、infra）的视图与 API 挂载到同一套导航体系中。跨子模块协作由三层基础设施完成：① `src/components/` 下的通用 UI 组件（Table、Form、Dialog、UploadFile、DictTag 等）被所有业务页面复用；② `src/utils/`、`src/hooks/`、`src/directives/` 提供认证、权限、表单校验、树形处理等横切能力；③ `src/api/` 按业务域划分但统一基于 `src/config/axios/service.ts` 封装的请求实例调用后端，配合 `src/store/modules/` 中的全局状态（用户、权限、字典、标签页等）实现跨页面数据共享。构建产物输出至 `yudao-ui-admin/`，多环境配置通过 `.env.*` 与 `vite.config.ts` 区分。
