- 路由定义统一采用 `{ path, component: () => import(...), name, meta }` 结构，并通过 `meta.hidden/title/icon/noCache/affix/breadcrumb/activeMenu/followAuth/canTo` 等字段控制侧边栏、面包屑与 keep-alive 行为。
- 所有业务子路由以 `Layout` 作为父组件包裹，非 Layout 的页面（Login/404/Redirect 等）直接挂载到根路径并在 meta 中标记 `hidden: true`。
- Axios 封装将通用逻辑集中在 service 拦截器中，业务层仅通过 index.ts 暴露的 get/post/delete/put/download/upload 方法发起请求，不直接使用 axios。
- 需要携带 token 的请求默认带上 Authorization 头，通过在请求配置中设置 `isToken: false` 或命中白名单来排除；租户信息通过 tenant-id / visit-tenant-id 请求头传递。
- 插件统一以 `setupXxx(app: App<Element>)` 函数形式导出，由应用入口按依赖顺序调用，避免在业务组件中直接 import 第三方库。
- 国际化文案通过 `useI18n()` 的 `t('key')` 获取，路由 meta.title 与 Axios 错误提示均走 i18n，保证多语言一致性。
