- API 文件按后端资源目录一一对应，每个 `index.ts` 导出 VO 接口与若干 `get/post/put/delete` 函数，统一通过 `request.get/post/put/delete` 调用。
- IM 领域将复杂交互拆分为 `composables/useXxx.ts`（如 useMessagePuller、useMessageSender、useVoicePlayer、useLiveKitRoom），组件仅负责渲染与事件转发。
- IM 状态按实体拆分多个 Pinia store（conversationStore/messageStore/friendStore/groupStore/channelStore/websocketStore/rtcStore），组件通过 `useXxxStore()` 获取而非 props 透传。
- WMS 各业务模块统一提供 `index.vue`（列表）、`xxxForm.vue`（新增/编辑）、`xxxDetail.vue`（详情）、`xxxPrint.vue`（打印）以及可选的 `components/*Select.vue` 选择器组件。
- IM 全局弹层（UserInfoCard、GroupInfoCard、ContextMenu、RtcCallContainer）在 `home/index.vue` 顶层挂载，由 store 或 composables 触发显示，避免在各子页面重复注册。
- IM 首屏初始化采用「先读 IDB 缓存 → 并发远端增量刷新 → 建 WS 拉离线消息」三段式流程，并用 `isInitializationActive` 守卫异步回调，防止组件卸载后继续操作。
