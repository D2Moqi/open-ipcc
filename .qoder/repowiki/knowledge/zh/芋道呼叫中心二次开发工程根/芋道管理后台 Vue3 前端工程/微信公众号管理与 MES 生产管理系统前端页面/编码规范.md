- 每个业务页面采用“搜索表单 + 表格列表 + 分页”三段式布局，查询参数集中定义在 `queryParams` 并通过 `ref`/`reactive` 管理。
- API 调用集中在 `src/api/<domain>/<module>/index.ts` 中，按 CRUD 命名导出函数（create/update/delete/get/getPage），视图层通过 `import * as XxxApi` 引入。
- 按钮级权限通过 `v-hasPermi="['domain:resource:action']"` 指令声明，删除等危险操作先调用 `message.delConfirm()` 或 `message.confirm()` 二次确认。
- 列表中的枚举/字典值统一使用 `dict-tag` 配合 `DICT_TYPE.*` 展示，避免硬编码文本。
- 复杂表单与列表拆分为独立 `.vue` 文件放在同级 `components/` 目录下，并通过 `index.ts` 统一 re-export 供父页面按需引入。
- 页面顶部统一放置 `doc-alert` 组件指向对应功能的在线文档地址，便于使用者查阅手册。
