模块按职责划分为三个并列子目录：
- `src/utils/`：无副作用的纯函数集合，按领域拆分为文件（如 `auth.ts` 管理 token/租户信息并依赖 `useCache` 持久化；`encrypt.ts`/`jsencrypt.ts` 负责 RSA 加解密；`routerHelper.ts`、`url.ts`、`routeParams.ts` 处理路由与 URL；`formRules.ts`、`formCreate.ts`、`propTypes.ts` 对接 Element Plus 表单校验与类型；`index.ts` 作为统一出口并提供 `withInstall` 组件包装器）。
- `src/hooks/web/`：基于 Vue 3 Composition API 的组合式 Hook，每个文件聚焦单一场景（如 `useTable` 封装分页/删除/导出/搜索参数联动；`useMessage` 封装 ElMessage/MessageBox/Notification 并注入 i18n；`useDesign` 暴露 SCSS 变量与前缀类生成；`useI18n`、`useLocale`、`useNProgress`、`useWatermark` 等），通过 `reactive`/`ref`/`computed`/`watch` 组织状态，并通过 `@/store/modules/*` 读取全局状态。
- `src/directives/`：以插件形式注册到 Vue App，`index.ts` 导出 `setupAuth`（注册 `v-hasRole`、`v-hasPermi`）和 `setupMountedFocus`，权限指令内部通过 `useUserStore` 判断当前用户权限集。
依赖方向单向：hooks/utils 可引用 store、api types、第三方库（lodash-es、element-plus），但业务页面仅消费本模块导出的函数/Hook/指令，不反向依赖业务组件。
