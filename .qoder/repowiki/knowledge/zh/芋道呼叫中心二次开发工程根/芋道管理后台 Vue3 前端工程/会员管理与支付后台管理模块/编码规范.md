- 列表页统一采用「搜索表单 + el-table + Pagination」三段式布局，查询参数集中在 `queryParams` reactive 对象中，搜索/重置分别调用 `handleQuery`/`resetQuery` 并重置 pageNo。
- 弹窗表单组件通过 `ref.open(type, id)` 暴露方法，提交成功后 emit `success` 事件，由父组件监听并刷新列表。
- API 文件按后端资源目录镜像组织，每个文件同时导出 TypeScript 接口类型与异步请求函数，页面通过 `import * as XxxApi from '@/api/...'` 统一引入。
- 前端权限通过 `v-hasPermi="['xxx:yyy:action']"` 指令与 `checkPermi([...])` 函数双重校验，按钮与下拉菜单项均按权限码条件渲染。
- 枚举/状态列统一使用 `dict-tag :type="DICT_TYPE.XXX" :value="row.field"` 渲染，筛选下拉通过 `getIntDictOptions`/`getStrDictOptions` 获取选项。
- 金额字段在表格中以分为单位存储，展示时通过 `/ 100` 并 `toFixed(2)` 转换为元显示。
