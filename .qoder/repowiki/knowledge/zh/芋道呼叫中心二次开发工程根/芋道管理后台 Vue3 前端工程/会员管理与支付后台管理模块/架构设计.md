模块按业务域划分为 `views/member`（会员）和 `views/pay`（支付）两大子目录，每个业务域遵循统一的「视图 + 组件 + API」三层结构：
- 视图层：每个功能域以 `index.vue` 作为列表页入口，使用 Element Plus 的 `el-form`/`el-table`/`Pagination` 组合实现搜索、分页、CRUD；详情通过 `detail/index.vue` 或独立 `xxxDetail.vue` 展示。
- 组件层：复用型选择器放在 `components/` 下（如 `MemberTagSelect`、`MemberLevelSelect`、`MemberGroupSelect`），表单弹窗拆分为独立的 `Form.vue` 并通过 `ref.open(type, id)` 暴露方法，成功回调统一触发父级 `getList()`。
- API 层：`src/api/member/*` 与 `src/api/pay/*` 按后端资源一一对应，每个目录导出 TypeScript 接口定义与基于 `@/config/axios` 的请求函数，页面仅通过命名导入调用。
- 权限控制：所有操作按钮通过 `v-hasPermi` 指令与 `checkPermi` 工具函数按菜单权限码（如 `member:user:update`、`pay:order:query`）进行显隐与可点击控制。
- 数据字典：状态、渠道、枚举类字段统一通过 `DICT_TYPE` 配合 `dict-tag`、`getIntDictOptions`/`getStrDictOptions` 渲染，避免硬编码。
- 依赖方向：视图 → 组件 → API → axios，组件之间通过 props/emits 通信，跨域复用选择器组件由 member 各子模块共享。
