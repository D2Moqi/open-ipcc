- 每个业务域在 views 和 api 下保持同名目录镜像，例如 `views/ai/chat/` 对应 `api/ai/chat/`，便于按功能快速定位前后端代码。
- 页面统一以 `index.vue` 作为路由入口，并在 `<script setup>` 顶部通过 `defineOptions({ name: '...' })` 声明组件名称。
- API 封装采用命名对象模式（如 `ChatConversationApi`、`ChatMessageApi`），将 VO 接口与 CRUD 方法集中在同一 `index.ts` 中导出。
- 复杂页面拆分为 `components/` 子目录存放可复用 UI 片段（如 message、conversation、form），主页面仅负责状态编排与事件转发。
- 表单与列表分离：编辑/新增逻辑抽到独立的 `Form.vue` 或 `form/index.vue`，由主列表通过 ref 调用 open 方法打开弹窗。
- 流式交互通过 `AbortController` 配合 `sendChatMessageStream` 回调处理 chunk，并在异常时调用 abort 停止流并清理状态。
