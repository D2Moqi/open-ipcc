模块按业务域划分为两大目录：`src/views/ai/` 下每个子目录（chat、image、knowledge、mindmap、model、music、workflow、write）对应一个 AI 功能域，采用 `index/index.vue` 作为用户入口、`manager/index.vue` 作为管理员列表页的对称结构；各页面内部再按 `components/` 拆分对话列表、消息渲染、表单步骤等细粒度组件（如 chat 下的 conversation/message/role）。`src/api/ai/` 与视图一一对应，每个领域一个 `index.ts` 暴露 API 对象（如 `ChatConversationApi`），通过统一的 `@/config/axios` 发起请求，VO 类型在文件内定义。`src/views/mall/` 为传统商城后台，按 product/promotion/trade/statistics/home 等子域组织，同样以 `index.vue` + `components/` + `form/` 的三层结构组织页面，并通过 `@/api/mall/*` 调用后端接口。整体依赖方向单向：view → api → axios，无跨域互相引用。
