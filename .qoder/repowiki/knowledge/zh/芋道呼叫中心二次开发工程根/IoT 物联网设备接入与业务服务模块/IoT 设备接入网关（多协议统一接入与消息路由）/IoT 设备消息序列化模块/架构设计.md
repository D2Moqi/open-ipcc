模块以 `IotMessageSerializer` 接口为核心抽象，定义 `serialize/deserialize/getType` 三个方法，统一契约；具体实现按协议格式拆分子包：`json` 下的 `IotJsonSerializer` 直接基于框架 `JsonUtils` 对 `IotDeviceMessage` 进行纯 JSON 编解码，`binary` 下的 `IotBinarySerializer` 实现自定义大端序二进制协议（魔术字 0x7E、版本、请求/响应类型、4 字节长度、变长消息 ID 与方法名、JSON 消息体），并提供 `isBinaryFormat` 快速探测入口。`IotMessageSerializerManager` 在构造时遍历 `IotSerializeTypeEnum` 枚举值，通过 switch 工厂模式实例化对应序列化器并缓存到 `EnumMap`，对外仅暴露 `get(type)` 获取器，从而将新增序列化类型的扩展点集中在枚举与工厂两处。依赖方向单向指向 `iot-core` 的 `IotDeviceMessage`、`IotSerializeTypeEnum` 与工具类，不反向被 core 引用，保证网关层可独立演进。
