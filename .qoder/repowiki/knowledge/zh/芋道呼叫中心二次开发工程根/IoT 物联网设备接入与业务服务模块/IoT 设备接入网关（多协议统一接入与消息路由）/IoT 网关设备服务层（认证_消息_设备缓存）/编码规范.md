- 每个业务领域均定义 `IXxxService` 接口与其 `XxxServiceImpl` 实现，并以 `@Service` 标注实现类。
- 对外部依赖统一通过 `@Resource` 注入，配置项通过 `IotGatewayProperties` 集中读取（如 token 密钥、RPC URL、超时）。
- 参数校验统一使用 `cn.hutool.core.lang.Assert` 的断言方法抛出异常。
- 设备信息访问一律走 `IotDeviceService` 的缓存查询，避免直接调用远端接口。
- 消息序列化/反序列化采用策略模式：根据设备的 `IotSerializeTypeEnum` 从 `IotMessageSerializerManager` 获取对应 `IotMessageSerializer` 执行编解码。
- 远端 HTTP 调用封装在私有 `doPost` 中，统一构造 `HttpEntity`、处理 `CommonResult<R>` 响应并在异常时返回统一的 `INTERNAL_SERVER_ERROR`。
