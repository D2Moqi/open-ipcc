模块按职责划分为三个子包：
- `auth`：`IotDeviceTokenService` 及其实现基于 hutool-jwt 对 productKey+deviceName 生成/校验 JWT，并通过 `IotGatewayProperties` 读取密钥与过期时间，同时暴露 `parseUsername` 解析 MQTT 用户名。
- `device`：`IotDeviceService` 通过两个相互联动的 Guava `LoadingCache`（按 id 与按 productKey/deviceName 双键）缓存远端设备信息，1 分钟过期；具体远端调用由同包下 `remote/IotDeviceApiImpl` 实现 `IotDeviceCommonApi`，使用 Spring `RestTemplate` 以固定 `/rpc-api/iot/...` 路径 POST 到 device 服务。
- `device/message`：`IotDeviceMessageService` 作为消息编解码门面，先经 `IotDeviceService` 查设备获取 `IotSerializeTypeEnum`，再委托 `IotMessageSerializerManager` 动态选择序列化器完成序列化/反序列化，并通过 `IotDeviceMessageProducer` 异步发送消息，发送前统一补充 messageId、reportTime、deviceId、tenantId、serverId 等后端字段。
依赖方向单向：message → device → remote；auth 独立不依赖其他子包。所有实现类均为 Spring `@Service`，通过 `@Resource` 注入依赖。
