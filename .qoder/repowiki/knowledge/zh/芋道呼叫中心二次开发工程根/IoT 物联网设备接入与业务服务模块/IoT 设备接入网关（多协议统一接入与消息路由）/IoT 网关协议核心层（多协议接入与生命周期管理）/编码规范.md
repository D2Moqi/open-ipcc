- 每个协议子包遵循统一结构：顶层 `IotXxxProtocol` + `IotXxxConfig` + `handler/upstream` + `handler/downstream`，必要时扩展 `manager` 与 `codec` 子目录。
- 协议实现均实现 `IotProtocol` 接口，并通过 `IotDeviceMessageUtils.generateServerId(port)` 生成全局唯一的 `serverId` 用于消息追踪。
- 下行消息统一继承 `AbstractIotProtocolDownstreamSubscriber`，重写 `handleMessage` 实现具体业务，Topic 与 Group 均由父类基于 `serverId` 派生以保证点对点消费。
- 协议实例的创建由 `IotProtocolManager` 集中根据 `IotProtocolTypeEnum` 分发，新增协议类型需同时修改枚举与 manager 的 switch 分支。
- 配置采用 `@ConfigurationProperties(prefix = "yudao.iot.gateway")` + `@Validated`，各协议专属配置以嵌套字段形式挂载到 `ProtocolProperties`，并使用 `@Valid` 触发级联校验。
- 日志输出统一采用 `[模块][动作][上下文]` 的三段式前缀格式（如 `[start][IoT HTTP 协议 ...]`、`[onMessage][...]`），便于在日志中快速定位来源。
