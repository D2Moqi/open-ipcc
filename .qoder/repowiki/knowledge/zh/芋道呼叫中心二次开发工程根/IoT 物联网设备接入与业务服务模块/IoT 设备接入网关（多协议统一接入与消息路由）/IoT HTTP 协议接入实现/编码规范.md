- 每个 HTTP 处理器定义一个静态常量 PATH 并在 IotHttpProtocol.start() 中通过 router.post(PATH).handler(...) 显式注册路由。
- 所有业务处理器继承 IotHttpAbstractHandler，仅实现 handle0(RoutingContext) 方法，由基类统一处理反序列化、异常与 CommonResult 响应写入。
- 需要认证的接口通过 Authorization 头携带 token，并由基类 beforeHandle 使用 IotDeviceTokenService.verifyToken 校验后与 pathParam 中的 productKey/deviceName 进行匹配。
- 对上游服务的调用通过 SpringUtil.getBean(...) 在构造函数中懒加载，避免将处理器声明为 Spring Bean。
- 参数校验集中使用 Hutool 的 Assert.* 断言，结合 invalidParamException 抛出统一的 400 错误。
