模块以 `IotHttpProtocol` 为入口，实现统一的 `IotProtocol` 接口，负责创建 Vert.x 实例、配置可选的 HTTPS（PEM 证书）、构建 Router 并挂载四个路由处理器：`/auth`（设备认证）、`/auth/register/device`（直连设备一型一密注册）、`/auth/register/sub-device/:productKey/:deviceName`（子设备动态注册）、`/topic/sys/:productKey/:deviceName/*`（上行消息上报）。所有业务处理器继承抽象基类 `IotHttpAbstractHandler`，由其统一完成请求体反序列化、全局异常捕获、以及除认证/注册外的路径自动校验 Authorization token 与 productKey/deviceName 匹配。下行方向通过 `IotHttpDownstreamSubscriber` 继承 `AbstractIotProtocolDownstreamSubscriber` 订阅 `IotMessageBus`，当前实现为空（HTTP 暂不支持下行推送）。启动时通过 SpringUtil 获取 `IotDeviceTokenService`、`IotDeviceCommonApi`、`IotDeviceMessageService` 等外部服务，依赖方向单向指向 gateway 的 service 层与 core 层的 message/topic 模型。
