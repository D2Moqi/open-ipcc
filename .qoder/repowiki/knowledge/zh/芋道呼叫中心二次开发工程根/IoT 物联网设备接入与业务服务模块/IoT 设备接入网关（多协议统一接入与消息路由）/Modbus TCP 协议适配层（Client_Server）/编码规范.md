- 协议实现类统一持有 `running` 状态标志，并在 `start()` 中幂等跳过重复启动、在 `stop()` 中按顺序停止订阅者→取消定时器→停止轮询→关闭连接→关闭 Vertx。
- 通过 `vertx.setPeriodic` 定时调用 `refreshConfig()` 刷新设备配置，并使用 `synchronized` 保证刷新过程的串行化。
- 所有 Modbus 功能码、异常掩码、读写映射集中在 `IotModbusCommonUtils` 中以静态常量与工具方法形式暴露，避免在各 Handler 中硬编码数值。
- 上行/下行处理采用成对的 `*UpstreamHandler` + `*DownstreamSubscriber` 结构，分别负责设备→网关与网关→设备的消息路由。
- 配置变更流程统一为：拉取配置列表 → `ensureConnection/updatePolling` → `cleanupRemovedDevices/cleanupMissingConfigs` 清理已删除或失效设备资源。
- 日志输出统一采用 `[模块][动作][关键信息]` 格式的字符串拼接方式，便于在日志中快速检索定位。
