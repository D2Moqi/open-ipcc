模块按协议划分为 tcp、udp、websocket 三个并列子包，每个子包遵循统一的四层结构：
- 协议入口层：`IotXxxProtocol` 实现 `IotProtocol` 接口，封装 `Vertx`、服务器实例（`NetServer`/`DatagramSocket`/`HttpServer`）、`serverId`、序列化器与连接管理器，并提供 `start()/stop()` 生命周期。
- 上行处理层：`handler/upstream/IotXxxUpstreamHandler` 实现 `Handler<NetSocket>` 或对应数据报处理器，完成粘包/拆包、反序列化为 `IotDeviceMessage`、按 method 路由到认证/注册/业务分支，并通过 `deviceMessageService.sendDeviceMessage` 投递到消息总线。
- 下行处理层：`handler/downstream/IotXxxDownstreamSubscriber` 继承 `AbstractIotProtocolDownstreamSubscriber`，订阅 `IotMessageBus` 中的下行消息并委托给 `IotXxxDownstreamHandler` 写出到具体连接。
- 连接/会话管理层：`manager/IotXxxConnectionManager`（TCP/WS）或 `IotUdpSessionManager`（UDP）维护 `ConcurrentHashMap` 形式的 socket→设备映射，提供注册、注销、按设备 ID 发送等能力。
依赖方向单向：Protocol → Upstream/Downstream Handler → ConnectionManager；TCP 额外通过 `codec/IotTcpFrameCodecFactory` + `IotTcpCodecTypeEnum` 反射创建固定长度/长度字段/自定义分隔符帧编解码器，实现可插拔的拆包策略。所有协议共享上层 `IotGatewayProperties`、`IotMessageSerializerManager`、`IotMessageBus` 等公共组件。
