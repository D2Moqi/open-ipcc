- HTTP Hook 处理器统一通过 Vert.x Router 注册 POST 路由，并在 handler 内部解析 `RoutingContext.body()` 为 `JsonObject` 后分支处理，异常时返回 EMQX 要求的 200 状态码或包含 result 字段的 JSON 响应。
- MQTT 连接与重连采用「定时检查 + closeHandler 触发」双通道模式，所有阻塞式重连逻辑通过 `vertx.executeBlocking` 执行以避免阻塞 event-loop。
- 配置类使用 Lombok `@Data` 配合 Jakarta Validation 注解（`@NotEmpty`、`@NotNull`、`@Min`、`@Max`）声明必填字段与取值范围，嵌套子配置（Will/Ssl/Http）通过 `@Valid` 启用级联校验。
- 上行/下行处理器均通过构造器注入 `IotEmqxProtocol` 引用，并通过 `SpringUtil.getBean(...)` 懒获取 Spring Bean（如 `IotDeviceMessageService`、`IotDeviceService`），避免在协议类中直接持有 Spring 容器。
- 日志输出统一采用 `[方法名][描述][变量]` 格式的带标签前缀，便于在网关日志中快速过滤 EMQX 协议相关条目。
