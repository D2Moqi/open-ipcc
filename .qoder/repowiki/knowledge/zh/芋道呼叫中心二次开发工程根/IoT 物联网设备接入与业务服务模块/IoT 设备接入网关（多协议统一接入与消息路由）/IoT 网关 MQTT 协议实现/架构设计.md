模块以 `IotMqttProtocol` 为入口实现 `IotProtocol` 接口，在 `start()` 中创建 Vert.x + `MqttServer` 并注册 endpointHandler，按 clientId 后缀区分注册流程（`|authType=register|`）与普通认证流程；连接建立后统一设置异常、关闭、心跳、发布、订阅等处理器。

- handler/upstream：继承抽象基类 `IotMqttAbstractHandler`，拆分为 `IotMqttAuthHandler`（CONNECT 认证、上线通知）、`IotMqttRegisterHandler`（一型一密动态注册）、`IotMqttUpstreamHandler`（属性/事件上报），通过 `IotDeviceMessageService` 序列化后写入消息总线。
- handler/downstream：`IotMqttDownstreamSubscriber` 继承 `AbstractIotProtocolDownstreamSubscriber` 从 `IotMessageBus` 消费下行消息，交由 `IotMqttDownstreamHandler` 反查在线设备并发送。
- manager：`IotMqttConnectionManager` 使用两个 `ConcurrentHashMap`（endpoint→ConnectionInfo、deviceId→endpoint）维护会话，提供注册、注销、按设备 ID 发消息、批量关闭等能力。
- 配置：`IotMqttConfig` 通过 `@Data` + Jakarta Validation 约束最大消息大小与连接超时，由上层 `IotGatewayProperties.ProtocolProperties` 注入。
依赖方向：Protocol → Handler → ConnectionManager / DeviceMessageService；Handler 不直接持有 Vertx/MqttServer，仅操作 `MqttEndpoint`，保证协议层与传输层解耦。
