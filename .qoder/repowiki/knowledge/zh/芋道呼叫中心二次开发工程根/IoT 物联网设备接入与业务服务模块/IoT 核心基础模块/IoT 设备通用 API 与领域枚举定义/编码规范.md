- 枚举统一使用 Lombok `@RequiredArgsConstructor` + `@Getter` 构造只读字段，并声明静态 `ARRAYS` 常量配合 `array()` 实现 `ArrayValuable` 接口。
- 字符串型枚举通过 `of(String)` 静态工厂方法结合 `ArrayUtil.firstMatch` 实现按 code 反查枚举值。
- DTO 采用 Lombok `@Data` + `@NoArgsConstructor` + `@AllArgsConstructor` 三注解组合，并使用 Jakarta Validation 的 `@NotEmpty` 标注必填字段。
- API 接口方法统一以 `CommonResult<T>` 包装返回值，入参使用独立的 ReqDTO/RespDTO 对象而非裸参数。
