本模块为 yudao-module-iot-core 的核心契约层，仅包含无实现的接口与常量/枚举，供上层 biz/service 及下游子模块依赖：
- `biz/IotDeviceCommonApi.java`：以纯 Java 接口形式暴露设备通用能力（设备认证、获取设备信息、直连/网关动态注册、Modbus 设备配置列表），所有方法统一返回 `CommonResult<T>`，DTO 集中在同包 `dto/` 下按请求/响应命名。
- `enums/`：集中存放跨模块复用的领域常量，按语义分目录——根级存放协议类型（`IotProtocolTypeEnum`）、序列化格式（`IotSerializeTypeEnum`）、消息方法（`IotDeviceMessageMethodEnum`，含上行/下行标记与 reply 禁用集合）；`device/` 下放设备生命周期状态（在线/离线/未激活）；`modbus/` 下放 Modbus 相关枚举（字节序、帧格式、工作模式、原始数据类型）。
- 依赖方向单向向外：本模块不依赖任何实现类，仅依赖框架层的 `CommonResult`、`ArrayValuable` 等基础类型，确保被各 IoT 子模块作为 stable contract 引入。
