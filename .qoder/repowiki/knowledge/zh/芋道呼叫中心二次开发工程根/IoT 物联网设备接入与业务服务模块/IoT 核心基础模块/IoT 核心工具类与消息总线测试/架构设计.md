模块按职责分为两个子目录：
- `main/java/.../util/` 放置纯静态工具类，无 Spring 依赖，仅依赖 Hutool 与 core 层 DTO/枚举：`IotDeviceAuthUtils` 实现阿里云风格的 MQTT 客户端 clientId/username/password/HmacSHA256 签名生成；`IotProductAuthUtils` 实现一型一密场景下 productSecret 的动态注册签名与校验；`IotDeviceMessageUtils` 统一处理 IotDeviceMessage 的标识符提取、属性值多策略解析（直接值→identifier→properties→data→value→单值Map）、事件值与服务调用参数抽取，以及消息总线 Topic 构建。
- `src/test/` 下分两类测试：`util/IotDeviceMessageUtilsTest` 针对消息解析工具进行覆盖性单元测试；`messagebus/core/{local,RocketMQ}` 通过 `@SpringBootTest` + `@Import(IotMessageBusAutoConfiguration.class)` 注入不同实现的 `IotMessageBus`，使用 `CountDownLatch` 等待异步消息投递完成，验证单/多订阅者、多 Topic 场景，其中 RocketMQ 测试默认 `@Disabled` 需外部 Broker 配合。
依赖方向单向：测试 → util 工具类；工具类仅依赖 core 层的 DTO、枚举、Topic 常量，不反向依赖业务或消息总线实现。
