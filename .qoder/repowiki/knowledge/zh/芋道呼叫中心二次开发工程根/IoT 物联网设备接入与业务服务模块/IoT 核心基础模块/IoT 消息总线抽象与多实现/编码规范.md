- 每个后端实现类均实现统一的 `IotMessageBus` 接口，并提供 `post(topic, message)` 与 `register(subscriber)` 两个核心方法。
- 订阅者通过 `IotMessageSubscriber<T>` 声明 `getTopic()`、`getGroup()`、`onMessage(T)`，并在实现中利用 `TypeUtil.getTypeArgument` 从泛型参数解析消息类型进行反序列化。
- 自动配置采用内部静态 `@Configuration` 类 + `@ConditionalOnProperty(prefix = "yudao.iot.message-bus", name = "type", havingValue = "...")` 按 type 值分支装配不同消息总线 Bean。
- 消息体统一通过 `JsonUtils.toJsonString` 序列化为字符串后再写入中间件，消费侧再按目标类型反序列化。
- 异步消费者容器在构造时创建、`@PostConstruct` 或 `register` 时启动，并通过 `@PreDestroy` 显式停止释放资源。
- 日志输出遵循 `[tag][...]` 格式（如 `[post]`、`[register]`、`[onMessage]`、`[destroy]`），便于按标签过滤追踪消息流转。
