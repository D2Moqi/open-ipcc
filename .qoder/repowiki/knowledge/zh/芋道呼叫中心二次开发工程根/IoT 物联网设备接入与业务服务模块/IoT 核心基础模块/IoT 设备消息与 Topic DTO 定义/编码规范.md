- Topic 相关 DTO 统一命名为 IotDeviceXxxReqDTO / IotDeviceXxxRespDTO，并按 auth、config、event、ota、property、service、state、topo 等业务域分目录组织。
- DTO 通过 Lombok @Data/@NoArgsConstructor/@AllArgsConstructor 生成基础能力，并在类注释中通过 @see 指向对应的 IotDeviceMessageMethodEnum 枚举值，表明该 DTO 是哪个 method 的 params。
- IotDeviceMessage 通过静态工厂方法（requestOf/replyOf/of/buildState*）构造消息，避免直接 new 对象，保证 id 与 reportTime 由 IotDeviceMessageUtils 统一生成。
- 需要设备归属信息的 DTO 复用 IotDeviceIdentity（productKey + deviceName）或在消息中携带 deviceId/tenantId/serverId 三要素。
- Topic 常量集中定义在 IotDeviceMessage 中并以 MESSAGE_BUS_*_TOPIC 命名，网关定向 Topic 通过 %s 占位符拼接 serverId。
