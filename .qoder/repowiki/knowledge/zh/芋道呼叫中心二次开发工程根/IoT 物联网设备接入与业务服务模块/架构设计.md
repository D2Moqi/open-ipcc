模块按依赖方向自下而上分层：
- yudao-module-iot-api 仅定义跨进程契约（RPC 接口、枚举、错误码），被 core 与 server 共同引用。
- yudao-module-iot-core 提供 IotMessageBus 抽象及 Kafka/RabbitMQ/Redis/RocketMQ/Local 多种实现，并通过 topic/* 下的 DTO 统一描述设备注册、属性上报、事件、OTA、拓扑等消息；IotDeviceCommonApi 作为设备通用能力被 gateway 与 server 双向调用。
- yudao-module-iot-gateway 是纯接入层 Spring Boot 应用，通过 IotProtocolManager 动态装配 HTTP/MQTT/CoAP/TCP/UDP/WebSocket/EMQX/Modbus 等协议处理器，上行数据经 IotDeviceMessageProducer → IotMessageBus 投递到 topic，下行指令由 AbstractIotProtocolDownstreamSubscriber 消费后路由至对应协议。
- yudao-module-iot-server 聚合 device/product/alert/ota/rule/thingmodel 等业务子模块，实现 IotDeviceApiImpl 暴露给 gateway 调用，同时通过 controller 暴露管理端 HTTP 接口，并使用 MQ consumer 消费 topic 完成规则引擎、告警、统计等后续处理。
三处关键耦合点：1) gateway ↔ server 通过 core 的 IotDeviceCommonApi 进行远程调用；2) 所有设备消息以 core/topic 中的 DTO 在 MQ 中流转；3) 协议扩展遵循 protocol/IotProtocol + handler/upstream|downstream 的统一目录约定。
