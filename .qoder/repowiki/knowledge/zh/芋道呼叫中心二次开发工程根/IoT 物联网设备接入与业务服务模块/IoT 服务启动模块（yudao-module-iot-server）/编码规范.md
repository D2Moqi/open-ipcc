- 每个领域（device/product/alert/ota/rule/thingmodel）均遵循 controller → service → dal（DO/Mapper/XML）三层分层，并按功能再分子包
- Controller 仅接收 VO 并委托 Service，Service 负责事务与跨子域编排，DAL 仅做数据访问
- DO 命名采用 IotXxxDO，Mapper 使用 MyBatis-Plus 的 BaseMapper 扩展，XML 映射文件置于 resources/mapper/{domain}/ 下
- 外部能力（MQ、Job、Security、Web、TDengine）统一收敛在 framework 目录下，按能力分包而非散落在各 domain
- 新增 sink/trigger/action 等扩展点通过策略接口（如 IotDataRuleAction、IotSceneRuleMatcher）注册，而非硬编码分支
