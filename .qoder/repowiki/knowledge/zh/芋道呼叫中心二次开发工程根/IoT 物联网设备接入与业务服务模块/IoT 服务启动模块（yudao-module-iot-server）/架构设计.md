本模块作为 yudao-module-iot 的独立可部署服务，通过 Spring Boot 启动类 IoTServerApplication 统一装配各领域层：controller/admin 下按 device/product/alert/ota/rule/thingmodel 划分管理端 HTTP 接口；service 层实现业务编排；dal 层以 MySQL + TDengine 双存储持久化（MySQL 存元数据，TDengine 存时序消息/属性），并通过 Redis 缓存设备上报时间与属性；mq.consumer 订阅设备消息并路由至规则引擎；framework 目录集中配置安全、Web、定时任务调度（IotSchedulerManager）、TDengine 表初始化（TDengineTableInitRunner）与 RPC 暴露（IoTDeviceApiImpl）。各领域子模块仅依赖共享基础设施与公共 DO/VO，跨域协作通过 Service 调用与 MQ 事件完成，避免直接耦合。
