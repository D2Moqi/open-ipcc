- 每个可插拔的触发器/条件都实现 `IotSceneRuleMatcher` 及其子接口，并通过 Spring 组件注册，由 `IotSceneRuleMatcherManager` 构造期自动收集并按 `getPriority()` 排序装配。
- 每个可插拔的动作实现 `IotSceneRuleAction` 接口并以 `getType()` 返回对应的 `IotSceneRuleActionTypeEnum`，由上层根据规则 Action 配置进行分派执行。
- Controller 层统一使用 `@Tag`、`@Operation`、`@Parameter` 描述 Swagger 文档，并通过 `@PreAuthorize("@ss.hasPermission('iot:scene-rule:...')")` 做细粒度权限控制。
- 定时器相关操作对 `SchedulerException` 进行 try-catch 并记录错误日志，保证单个任务注册失败不影响其他任务。
- 匹配器与动作类均使用 `@Slf4j` 输出结构化日志，关键路径包含 `[模块名][方法名]` 前缀便于检索。
