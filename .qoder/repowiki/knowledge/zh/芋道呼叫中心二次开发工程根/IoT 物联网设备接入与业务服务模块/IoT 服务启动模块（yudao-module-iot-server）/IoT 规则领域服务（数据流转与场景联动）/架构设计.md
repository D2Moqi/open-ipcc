本模块按三层划分：controller/admin/rule 提供 CRUD 接口；service/rule 下分 data_rules（IotDataRuleService/IotDataSinkService）与 scene_rules（IotSceneRuleService）两条独立业务线，分别对应设备消息路由与场景联动引擎；dal/dataobject/rule 集中存放 MyBatis-Plus DO 及多态化的 Sink 配置类。

跨子模块的协作方式：
- 数据流转规则与场景联动规则共享同一套 DO/VO 分层约定（DO 持久化、VO 入参出参），但各自维护独立的 Service、Matcher/Action 扩展点，互不耦合。
- Sink 体系采用统一抽象 IotAbstractDataSinkConfig + 各具体 Config（Database/HTTP/MQ/TCP/WebSocket/Redis/RabbitMQ/RocketMQ），由 service 层根据规则配置动态选择对应 Action 实现（IotXxxDataRuleAction）完成消息投递。
- 场景联动规则通过 IotSceneRuleMatcherManager 注册多种 TriggerMatcher 与 ConditionMatcher，再由 TimerHandler 周期性调度执行 SceneRuleAction，形成“定时→匹配→动作”的流水线。
- 控制器仅负责参数校验与调用 Service，不包含业务编排逻辑，确保 rule_domain 内部以 Service 为唯一入口向外暴露能力。
