- 每个业务实体在 VO 层提供 PageReqVO（继承 PageParam，含名称/状态/时间范围查询字段）、SaveReqVO（新增/修改）、RespVO（返回字段）三件套，命名遵循 `IotXxxPageReqVO/SaveReqVO/RespVO`。
- DO 统一继承 `BaseDO`，使用 Lombok `@Data/@Builder/@NoArgsConstructor/@AllArgsConstructor` 组合，并通过 `@TableName` + `@KeySequence` 声明表与主键序列。
- 复杂结构字段（如 Sink 配置、SourceConfig 数组）通过 `@TableField(typeHandler = JacksonTypeHandler.class)` 以 JSON 形式持久化。
- 枚举型字段（status、type）使用 `@InEnum(CommonStatusEnum.class)` 或自定义枚举进行校验，并在注释中指明对应枚举。
- 数据目的配置采用抽象基类 + Jackson 多态注解的方式声明所有子类映射，新增 Sink 类型时需在 `@JsonSubTypes` 中注册新的 type 编号。
