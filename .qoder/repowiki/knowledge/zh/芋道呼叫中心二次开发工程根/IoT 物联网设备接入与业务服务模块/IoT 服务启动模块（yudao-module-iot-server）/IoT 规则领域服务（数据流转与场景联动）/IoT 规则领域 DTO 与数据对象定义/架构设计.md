本模块按职责划分为两层：
- `controller/admin/rule/vo` 层：面向管理后台 API 的请求/响应 VO，按业务域拆分为 `data/rule`（数据流转规则）、`data/sink`（数据目的）、`scene`（场景联动）三个子包，每个实体配套 PageReqVO / SaveReqVO / RespVO 三件套。
- `dal/dataobject/rule` 层：MyBatis-Plus 的持久化 DO，对应数据库表 `iot_data_rule`、`iot_data_sink`、`iot_scene_rule`，继承 `BaseDO` 并提供主键序列。

核心设计点：
- 数据目的配置采用抽象基类 `IotAbstractDataSinkConfig` + Jackson `@JsonTypeInfo/@JsonSubTypes` 的多态序列化机制，通过 `type` 字段动态映射到 HTTP/TCP/WebSocket/MQTT/Database/Redis/RocketMQ/RabbitMQ/Kafka 等具体配置子类；DO 与 SaveReqVO 均直接持有该抽象类型字段，由 JacksonTypeHandler 完成 JSON 存取。
- 数据流转规则 `IotDataRuleDO` 通过内部静态类 `SourceConfig` 描述监听的数据源（消息方法、产品、设备、物模型标识），并以 `List<Long>` sinkIds 关联多个数据目的，实现“一对多”转发关系。
- 场景联动规则 `IotSceneRuleDO` 以触发器（Trigger）与执行器（Action）列表表达事件驱动流程。
依赖方向单向：VO → DO → 框架枚举/注解，不反向引用 Controller。
