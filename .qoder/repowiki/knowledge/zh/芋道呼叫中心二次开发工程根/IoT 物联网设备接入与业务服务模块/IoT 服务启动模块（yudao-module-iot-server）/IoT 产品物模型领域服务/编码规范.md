- Controller 方法统一使用 `@Tag`、`@Operation`、`@Parameter` 描述接口，并通过 `@PreAuthorize("@ss.hasPermission('iot:thing-model:*')")` 进行细粒度权限控制。
- 请求/响应对象拆分为 VO 类（`*ReqVO`、`*RespVO`），Controller 中通过 `BeanUtils.toBean` 在 DO 与 VO 之间转换，避免直接暴露 DO。
- Service 实现类对写操作加 `@Transactional(rollbackFor = Exception.class)`，并在事务提交后通过 `getSelf()` 调用带 `@CacheEvict` 的方法以强制触发 AOP 缓存失效。
- 物模型功能（属性/事件/服务）通过 `IotThingModelDO` 中的 JSON 字段 `property`、`event`、`service` 存储，并使用 JacksonTypeHandler 自动序列化/反序列化。
- 数据类型规范采用继承体系：`ThingModelDataSpecs` 为基类，各具体类型（数值、文本、数组、结构体、布尔/枚举等）独立文件实现，便于扩展新数据类型。
- 需要跨租户访问的缓存查询方法统一标注 `@TenantIgnore`，并在注释中显式提醒调用方注意租户隔离风险。
