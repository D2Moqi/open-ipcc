模块按 Controller-Service-DO 三层组织：`controller/admin/thingmodel/IotThingModelController` 暴露 `/iot/thing-model` REST 接口，通过 `@PreAuthorize` 控制权限并调用 Service；`service/thingmodel/IotThingModelService` 定义物模型领域接口，`IotThingModelServiceImpl` 实现 CRUD、分页、列表查询、缓存读取与设备上报值类型转换，并通过 `@Lazy` 注入 `IotProductService`、`IotDeviceModbusPointService` 解决循环依赖；数据层以 `dal/dataobject/thingmodel/IotThingModelDO` 为根实体，映射到 `iot_thing_model` 表，其中 `property`、`event`、`service` 三个字段通过 MyBatis-Plus 的 `JacksonTypeHandler` 序列化为 JSON，分别对应 `model/ThingModelProperty`、`ThingModelEvent`、`ThingModelService` 三种物模型功能定义，其数据类型规范集中在 `model/dataType/` 下按具体类型拆分（如 `ThingModelNumericDataSpec`、`ThingModelArrayDataSpecs` 等）。读写路径上，写操作经 `@Transactional` 持久化后通过 `getSelf()` 触发 `@CacheEvict` 清理 Redis 缓存键 `RedisKeyConstants.THING_MODEL_LIST`，读操作通过 `@Cacheable` + `@TenantIgnore` 提供跨租户的物模型列表缓存。
