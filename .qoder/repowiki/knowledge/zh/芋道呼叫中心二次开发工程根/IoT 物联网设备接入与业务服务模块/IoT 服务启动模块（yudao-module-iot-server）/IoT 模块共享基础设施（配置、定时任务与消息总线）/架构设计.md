本模块按横切关注点划分为 framework、job、mq 三个子目录，均位于 iot-server 模块下，作为业务层的共享基础设施。
- framework：以 Spring `@Configuration` 为中心进行能力装配。`IotJobConfiguration` 通过 `initMethod=start/destroyMethod=stop` 注册自管理的 `IotSchedulerManager`（基于 Quartz + LocalDataSourceJobStore 集群），用于动态增删改查规则场景的定时器；`SecurityConfiguration` 暴露 `AuthorizeRequestsCustomizer` Bean 开放 Swagger、Actuator、Druid 及 RPC 接口白名单；`RpcConfiguration` 使用 `@EnableFeignClients` 声明对 system 模块的 Feign 客户端；`IotWebConfiguration` 借助 `YudaoSwaggerAutoConfiguration.buildGroupedOpenApi("iot")` 生成独立 API 分组；`TDengineTableInitRunner` 实现 `ApplicationRunner`，启动时调用 `IotDeviceMessageService.defineDeviceMessageStable()` 建表，失败则 `System.exit(1)` 阻断启动；`YudaoIotProperties` 集中管理 keepAliveTime/keepAliveFactor 等运行时参数；`TDengineDS` 注解封装 `@DS("tdengine")`，配合 `TDengineTableField` 提供字段类型常量与驼峰转下划线工具。
- job：分为两类——由 XXL-Job 中心调度的 `@XxlJob` 组件（`IotDeviceOfflineCheckJob`、`IotOtaUpgradeJob`、`IotSceneRuleJob` 中的部分逻辑），以及由本地 Quartz 动态注册的 `IotSceneRuleJob extends QuartzJobBean`，后者通过 `JobDataMap` 传递 sceneRuleId 并调用 `IotSceneRuleService.executeSceneRuleByTimer`。
- mq：所有消费者实现统一接口 `IotMessageSubscriber<IotDeviceMessage>`，在 `@PostConstruct` 中向 `IotMessageBus` 注册自身，并通过 `getTopic()/getGroup()` 指定订阅主题与消费组；`device` 包处理设备上行消息（更新上报时间、强制上线、转发至 `IotDeviceMessageService`），`rule` 包分别委派给数据规则与场景规则服务，全部包裹在 `TenantUtils.execute(tenantId, ...)` 中以支持多租户隔离。
依赖方向：framework/job/mq 仅依赖 service/dal/core 等上层能力，不反向被业务模块引用，形成稳定的横向支撑层。
