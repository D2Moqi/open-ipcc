- 框架级能力通过独立的 `@Configuration` 类集中装配，并以 `proxyBeanMethods = false` 或 `value = "xxxConfiguration"` 明确命名以避免冲突。
- MQ 消费者统一实现 `IotMessageSubscriber<T>` 接口，在 `@PostConstruct` 中通过 `IotMessageBus.register(this)` 完成注册，并通过 `getTopic()/getGroup()` 声明订阅信息。
- 定时任务按职责分目录组织（device/ota/rule），XXL-Job 任务标注 `@XxlJob` 与 `@TenantJob`，Quartz 任务继承 `QuartzJobBean` 并通过静态 `buildJobName/buildJobDataMap` 工厂方法构造 JobKey 与参数。
- 跨租户操作统一使用 `TenantUtils.execute(tenantId, ...)` 包裹业务逻辑，保证上下文隔离。
- TDengine 相关代码通过自定义 `@TDengineDS` 注解间接复用 dynamic-datasource 的 `@DS("tdengine")`，字段名统一经 `TDengineTableField.buildFieldName` 转为小写下划线格式。
- 可配置项集中在 `@Component` + Lombok `@Data` 的 Properties 类中（如 `YudaoIotProperties`），由外部配置文件注入而非硬编码。
