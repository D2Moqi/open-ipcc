- 每个业务实体采用 Service 接口 + ServiceImpl 实现的成对设计，接口方法以 create/update/delete/get/page 等动词命名并返回 DO 或 PageResult<DO>。
- 控制器方法统一使用 @Operation + @Parameter + @PreAuthorize("@ss.hasPermission('iot:product:...')") 描述接口并声明细粒度权限点。
- 请求参数与响应分别通过独立的 ReqVO/RespVO 类承载，并使用 BeanUtils.toBean 在 Controller 中完成 DO ↔ VO 转换。
- DO 实体继承 BaseDO/TenantBaseDO 并通过 Lombok @Data/@Builder/@NoArgsConstructor/@AllArgsConstructor 生成样板代码，配合 MyBatis-Plus 注解映射表结构。
- 枚举字段通过注释引用对应枚举类（如 IotProductStatusEnum、IotProductDeviceTypeEnum），而非内联定义常量。
