模块采用典型的 Controller-Service-DO 三层结构：
- `controller/admin/device/` 下按业务子域拆分为 device、group、message、modbus、property 五个子包，每个子包对应一个 Spring `@RestController`（如 `IotDeviceController`、`IotDeviceGroupController`、`IotDeviceMessageController`、`IotDeviceModbusConfigController`、`IotDevicePropertyController`），统一通过 `CommonResult` 返回并借助 `@PreAuthorize("@ss.hasPermission(...)")` 做权限控制。
- `service/device/` 中每个实体均定义 `IXxxService` 接口与 `IXxxServiceImpl` 实现，并按功能进一步细分到 `message/`、`property/` 子包；核心 `IotDeviceService` 同时承担设备基础 CRUD、网关拓扑（bind/unbound/topo 处理）、动态注册（直连/子设备）等跨领域编排逻辑。
- `dal/dataobject/device/` 存放 MyBatis-Plus 实体 DO（`IotDeviceDO`、`IotDeviceGroupDO`、`IotDeviceMessageDO`、`IotDeviceModbusConfigDO`、`IotDeviceModbusPointDO`、`IotDevicePropertyDO`），继承 `TenantBaseDO` 支持多租户，使用 `@TableName`、`@KeySequence`、`@TableField(typeHandler=...)` 等注解映射数据库表。
- VO 层位于 controller 下的 `vo/` 子目录，按请求/响应分类（如 `device/IotDeviceSaveReqVO`、`device/IotDeviceRespVO`），由 Controller 经 `BeanUtils.toBean` 在 DO 与 VO 之间转换。
- 依赖方向单向：Controller → Service → DO（MyBatis Mapper 在更下层），Service 还依赖 `core.biz.dto`、`core.topic.*`、`core.enums.device` 等 core 模块完成认证、MQTT 拓扑消息与状态枚举处理。
