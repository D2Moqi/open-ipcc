模块遵循 controller-service-dal 三层结构：
- controller/admin/ota 下按实体划分三个 Controller（Firmware/Task/TaskRecord），统一以 `@Tag("管理后台 - IoT OTA ...")` 标注并通过 `@PreAuthorize("@ss.hasPermission('iot:ota-...')")` 做权限控制，请求/响应通过 VO 隔离。
- service/ota 中每个实体对应一个接口+实现类（IotOtaFirmwareService、IotOtaTaskService、IotOtaTaskRecordService），业务逻辑集中在 ServiceImpl，使用 `@Transactional(rollbackFor = Exception.class)` 保证事务；TaskServiceImpl 通过 `@Lazy` 注入 TaskRecordService 避免循环依赖，并在 createOtaTask/cancelOtaTask 中协调 Device、Firmware、Task、TaskRecord 多表状态流转。
- dal/dataobject/ota 仅存放 MyBatis-Plus DO（IotOtaFirmwareDO/IotOtaTaskDO/IotOtaTaskRecordDO），继承 BaseDO 并使用 `@TableName` + `@KeySequence` 适配多数据库主键策略。
- 依赖方向单向：controller → service → (mapper + 其他领域 service)，DO 不反向引用上层。
