- 每个实体采用「Controller + Service 接口 + ServiceImpl + DO + VO」五件套拆分，VO 按 firmware/task/record 子包组织并与 DO 一一对应。
- Controller 方法统一返回 `CommonResult<T>`，并通过 `@Operation(summary=...)` 与 `@PreAuthorize("@ss.hasPermission('iot:ota-...')")` 描述 API 与权限点。
- Service 层对跨表写操作使用 `@Transactional(rollbackFor = Exception.class)`，并通过 `BeanUtils.toBean` 在 VO/DO 之间转换。
- 业务校验失败统一通过 `exception(ErrorCodeConstants.XXX)` 抛出服务异常，而非直接抛 RuntimeException。
- DO 继承 BaseDO 并标注 `@TableName` + `@KeySequence`，字段通过 Lombok `@Data/@Builder` 生成，注释说明枚举或关联关系。
