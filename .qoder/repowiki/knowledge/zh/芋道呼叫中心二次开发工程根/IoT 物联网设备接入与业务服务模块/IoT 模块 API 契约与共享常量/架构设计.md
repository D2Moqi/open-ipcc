本模块为纯 Java 库（packaging=jar），不依赖业务实现，仅作为 yudao-module-iot 对外的契约层。目录结构分为两层：`api/` 包用于声明暴露给其它模块调用的 RPC 接口（当前由 `package-info.java` 占位）；`enums/` 包集中存放跨模块共享的领域枚举与常量，并按业务域划分为 alert、ota、product、rule、thingmodel 等子包。`ApiConstants` 统一维护 RPC 前缀 `/iot` 与版本号；`ErrorCodeConstants` 以接口形式按业务域分段定义错误码（如产品、设备、OTA、数据流转规则、告警等）；`DictTypeConstants` 集中声明字典类型键名。依赖方向单向向外：仅依赖 `yudao-common` 及 spring-web/jackson/validation（标记为 provided/optional），确保被依赖方无需引入运行时框架即可编译。
